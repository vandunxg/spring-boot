= Executable Jar Format

Module `spring-boot-loader` cho phép Spring Boot hỗ trợ executable jar và war file.
Nếu bạn dùng Maven plugin hoặc Gradle plugin, executable jar được sinh tự động và nhìn chung bạn không cần biết chi tiết cách chúng hoạt động.

Nếu bạn cần tạo executable jar từ build system khác, hoặc chỉ đơn giản là tò mò về công nghệ bên dưới, appendix này cung cấp một số thông tin nền.
