[[build-info]]
= Tích hợp với Actuator

Spring Boot Actuator hiển thị thông tin liên quan đến build nếu file `META-INF/build-info.properties` tồn tại.
Goal `build-info` tạo file này với coordinates của project và thời điểm build.
Goal này cũng cho phép thêm tùy ý số lượng property bổ sung, như trong ví dụ sau:

[source,xml,indent=0,subs="verbatim,attributes"]
----
include::example$build-info/pom.xml[tags=build-info]
----

Configuration này sẽ tạo `build-info.properties` tại vị trí dự kiến với ba key bổ sung.

NOTE: `java.version` được kỳ vọng là một property thông thường có sẵn trong project.
Property này sẽ được interpolate như bạn mong đợi.
