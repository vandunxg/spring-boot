[[maven-plugin]]
= Maven Plugin

Spring Boot Maven Plugin cung cấp khả năng hỗ trợ Spring Boot trong https://maven.org[Apache Maven].
Plugin này cho phép package các executable jar hoặc war archive, chạy Spring Boot application, generate build information và start Spring Boot application trước khi chạy các integration test.

Để sử dụng plugin này, bạn phải dùng Maven 3.6.3 trở lên.

Ngoài user guide này, bạn cũng có thể xem xref:api/java/index.html[tài liệu API].
