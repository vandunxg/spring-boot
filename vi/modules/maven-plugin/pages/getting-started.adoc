= Bắt đầu

Để sử dụng Spring Boot Maven Plugin, hãy thêm XML phù hợp vào section `plugins` trong `pom.xml`, như trong ví dụ sau:

[source,xml,indent=0,subs="verbatim,attributes"]
----
include::example$getting-started/pom.xml[tags=getting-started]
----

ifeval::["{build-type}" == "commercial"]
Plugin được publish lên Spring Commercial repository.
Bạn phải configure build để truy cập repository này.
Việc này thường được thực hiện thông qua một local artifact repository dùng để mirror nội dung của Spring Commercial repository.
Ngoài ra, dù không được khuyến nghị, bạn cũng có thể truy cập trực tiếp Spring Commercial repository.
Trong cả hai trường hợp, xem https://docs.vmware.com/en/Tanzu-Spring-Runtime/Commercial/Tanzu-Spring-Runtime/spring-enterprise-subscription.html[tài liệu Tanzu Spring Runtime] để biết thêm chi tiết.
endif::[]
