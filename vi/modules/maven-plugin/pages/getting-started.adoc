ifeval::["{build-type}" == "commercial"]
Plugin được publish lên Spring Commercial repository.
Bạn phải configure build để access repository này.
Thông thường thực hiện qua local artifact repository mirror content của Spring Commercial repository.
Ngoài ra, dù không được khuyến nghị, Spring Commercial repository cũng có thể access trực tiếp.
Trong cả hai case, xem https://docs.vmware.com/en/Tanzu-Spring-Runtime/Commercial/Tanzu-Spring-Runtime/spring-enterprise-subscription.html[Tanzu Spring Runtime documentation] để biết thêm.
endif::[]
