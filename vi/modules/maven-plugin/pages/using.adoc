[[using]]
= Sử dụng Plugin

Người dùng Maven có thể kế thừa từ project `spring-boot-starter-parent` để nhận các default hợp lý.
Parent project cung cấp các feature sau:

* Java 17 làm compiler level mặc định.
* Source encoding UTF-8.
* Compile với `-parameters`.
* Một section dependency management, được kế thừa từ POM `spring-boot-dependencies`, quản lý version của các dependency phổ biến.
Section dependency management này cho phép bỏ tag `<version>` cho các dependency đó khi được dùng trong POM riêng.
* Một execution của xref:maven-plugin:packaging.adoc#packaging.repackage-goal[`repackage` goal] với execution id `repackage`.
* Một `native` profile cấu hình build để có thể generate Native image.
* https://maven.apache.org/plugins/maven-resources-plugin/examples/filter.html[Resource filtering] hợp lý.
* Plugin configuration hợp lý ({url-git-commit-id-maven-plugin}[`Git Commit Id Plugin`] và https://maven.apache.org/plugins/maven-shade-plugin/[shade]).
* Resource filtering hợp lý cho `application.properties` và `application.yml`, bao gồm các file theo profile (ví dụ: `application-dev.properties` và `application-dev.yml`).

NOTE: Vì các file `application.properties` và `application.yml` chấp nhận Spring-style placeholder (`${...}`), Maven filtering được thay đổi để sử dụng placeholder `@..@`.
(Bạn có thể override điều này bằng cách đặt một Maven property có tên `resource.delimiter`.)

[NOTE]
====
`spring-boot-starter-parent` set property `maven.compiler.release`, giới hạn các option `--add-exports`, `--add-reads` và `--patch-module` https://openjdk.org/jeps/247[nếu chúng modify system modules].
Nếu cần sử dụng các option đó, hãy unset `maven.compiler.release`:

[source,xml,indent=0,subs="verbatim,quotes,attributes"]
----
<maven.compiler.release></maven.compiler.release>
----

Sau đó configure source và target option:

[source,xml,indent=0,subs="verbatim,quotes,attributes"]
----
<maven.compiler.source>${java.version}</maven.compiler.source>
<maven.compiler.target>${java.version}</maven.compiler.target>
----
====



[[using.parent-pom]]
== Kế thừa Starter Parent POM

Để configure project kế thừa từ `spring-boot-starter-parent`, hãy set `parent` như sau:

[source,xml,subs="verbatim,quotes,attributes"]
----
<!-- Inherit defaults from Spring Boot -->
<parent>
	<groupId>org.springframework.boot</groupId>
	<artifactId>spring-boot-starter-parent</artifactId>
	<version>{version-spring-boot}</version>
</parent>
----

NOTE: Bạn chỉ cần specify Spring Boot version number trên dependency này.
Nếu import thêm starter, bạn có thể an toàn bỏ version number.

Với setup đó, bạn cũng có thể override từng dependency bằng cách override một property trong project.
Ví dụ, để sử dụng version khác của SLF4J library và Spring Data release train, thêm nội dung sau vào `pom.xml`:

[source,xml,indent=0,subs="verbatim,attributes"]
----
include::example$using/different-versions-pom.xml[tags=different-versions]
----

Xem section xref:appendix:dependency-versions/properties.adoc[Dependency Versions Properties] trong Spring Boot reference để biết danh sách đầy đủ các dependency version property.

WARNING: Mỗi Spring Boot release được design và test với một tập third-party dependency cụ thể.
Việc override version có thể gây ra compatibility issue và nên được thực hiện cẩn thận.

== Sử dụng Spring Boot không có Parent POM

[[using.overriding-command-line]]
== Override Settings trên Command Line

Plugin cung cấp một số user property bắt đầu bằng `spring-boot` để bạn customize configuration từ command line.

Ví dụ, bạn có thể điều chỉnh các profile được enable khi chạy application như sau:

[source,shell]
----
$ mvn spring-boot:run -Dspring-boot.run.profiles=dev,local
----

Nếu muốn vừa có default vừa cho phép override trên command line, bạn nên kết hợp một project property do user cung cấp với MOJO configuration.

[source,xml,indent=0,subs="verbatim,attributes"]
----
include::example$using/default-and-override-pom.xml[tags=default-and-override]
----

Cấu hình trên đảm bảo `local` và `dev` được enable theo mặc định.
Giờ đây một dedicated property đã được expose, và property này cũng có thể được override trên command line:

[source,shell]
----
$ mvn spring-boot:run -Dapp.profiles=test
----
