[[run]]
= Chạy Application bằng Maven

Plugin bao gồm goal `run`, có thể dùng để launch application từ command line, như trong ví dụ sau:

[source,shell]
----
$ mvn spring-boot:run
----

Application arguments có thể được chỉ định bằng parameter `arguments`; xem xref:run.adoc#run.examples.using-application-arguments[sử dụng application arguments] để biết thêm chi tiết.

Application chạy trong forked process và việc set properties trên command line sẽ không ảnh hưởng đến application.
Nếu cần chỉ định một số JVM arguments (tức là cho mục đích debugging), bạn có thể dùng parameter `jvmArguments`; xem xref:run.adoc#run.examples.debug[Debug application] để biết thêm chi tiết.
Plugin cũng có hỗ trợ riêng cho xref:run.adoc#run.examples.system-properties[system properties] và xref:run.adoc#run.examples.environment-variables[environment variables].

Vì việc enable profile khá phổ biến, có một `profiles` property chuyên dụng cung cấp shortcut cho `-Dspring-boot.run.jvmArguments="-Dspring.profiles.active=dev"`; xem xref:run.adoc#run.examples.specify-active-profiles[chỉ định active profiles].

Spring Boot `devtools` là một module cải thiện development-time experience khi làm việc với Spring Boot applications.
Để enable module này, chỉ cần thêm dependency sau vào project:

[source,xml,indent=0,subs="verbatim,attributes"]
----
include::example$running/devtools-pom.xml[tags=devtools]
----

Khi `devtools` đang chạy, nó detect các thay đổi khi bạn recompile application và tự động refresh application.
Điều này áp dụng không chỉ cho resources mà còn cho code.

Devtools cũng có thể được configure để chỉ refresh browser khi static resources thay đổi và ignore các code changes.
Để làm vậy, hãy disable devtools code-change restart bằng cách set property sau trong project:

[configprops%novalidate,yaml]
----
spring:
  devtools:
    restart:
      enabled: false
----

Trước `devtools`, plugin mặc định hỗ trợ hot refresh resources, nhưng hiện đã disable tính năng này để ưu tiên solution được mô tả ở trên.
Bạn có thể restore tính năng này bất kỳ lúc nào bằng cách configure project:

[source,xml,subs="verbatim,attributes"]
----
include::example$running/hot-refresh-pom.xml[tags=hot-refresh]
----

Khi `addResources` được enable, mọi directory `src/main/resources` sẽ được thêm vào application classpath khi bạn run application và mọi bản duplicate tìm thấy trong classes output sẽ bị remove.
Điều này cho phép hot refresh resources, có thể rất hữu ích khi develop web applications.
Ví dụ, bạn có thể làm việc trên các file HTML, CSS hoặc JavaScript và thấy thay đổi ngay lập tức mà không cần recompile application.
Đây cũng là một cách hữu ích để các front-end developers làm việc mà không cần download và install Java IDE.

NOTE: Một side effect của việc sử dụng feature này là resource filtering tại build time sẽ không hoạt động.

Để nhất quán với goal `repackage`, goal `run` build classpath theo cách mọi dependency bị exclude trong plugin configuration cũng bị exclude khỏi classpath.
Để biết thêm chi tiết, xem xref:packaging.adoc#packaging.examples.exclude-dependency[ví dụ chuyên dụng].

Đôi khi việc run một test variant của application là hữu ích.
Ví dụ, nếu bạn muốn xref:reference:features/dev-services.adoc#features.dev-services.testcontainers.at-development-time[sử dụng Testcontainers tại development time] hoặc dùng một số test stubs.
Với mục đích này, hãy dùng goal `test-run`, vốn có nhiều feature và configuration options giống như `run`.

=== Debug Application

Các goal `run` và `test-run` run application trong forked process.
Nếu cần debug application, bạn nên thêm các JVM arguments cần thiết để enable remote debugging.
Configuration sau sẽ suspend process cho đến khi một debugger kết nối vào port 5005:

[source,xml,indent=0,subs="verbatim,attributes"]
----
include::example$running/debug-pom.xml[tags=debug]
----

Bạn cũng có thể chỉ định các arguments này trên command line:

[source,shell]
----
$ mvn spring-boot:run -Dspring-boot.run.jvmArguments=-agentlib:jdwp=transport=dt_socket,server=y,suspend=y,address=*:5005
----

=== Sử dụng System Properties

System properties có thể được chỉ định bằng attribute `systemPropertyVariables`.
Ví dụ sau set `property1` thành `test` và `property2` thành 42:

[source,xml,indent=0,subs="verbatim,attributes"]
----
include::example$running/system-properties-pom.xml[tags=system-properties]
----

Nếu value rỗng hoặc không được define (tức là `<my-property/>`), system property sẽ được set với empty String làm value.
Maven trim các values được chỉ định trong POM, vì vậy không thể chỉ định bằng mechanism này một System property cần bắt đầu hoặc kết thúc bằng space; hãy cân nhắc dùng `jvmArguments` thay thế.

Bất kỳ Maven variable kiểu String nào cũng có thể được pass dưới dạng system property.
Mọi attempt pass Maven variable có kiểu khác (ví dụ một variable kiểu `List` hoặc `URL`) sẽ khiến variable expression được pass literal (chưa được evaluate).

Parameter `jvmArguments` được ưu tiên hơn các system properties được define bằng mechanism ở trên.
Trong ví dụ sau, value của `property1` là `overridden`:

[source,shell]
----
$ mvn spring-boot:run -Dspring-boot.run.jvmArguments="-Dproperty1=overridden"
----

[[run.examples.using-application-arguments]]
=== Sử dụng Application Arguments

Application arguments có thể được chỉ định bằng attribute `arguments`.
Ví dụ sau set hai arguments: `property1` và `property2=42`:

[source,xml,indent=0,subs="verbatim,attributes"]
----
include::example$running/application-arguments-pom.xml[tags=application-arguments]
----

Trên command line, các arguments được phân tách bằng space giống như `jvmArguments`.
Nếu một argument chứa space, hãy bảo đảm quote argument đó.
Trong ví dụ sau, có hai arguments: `property1` và `property2=Hello World`:

[source,shell]
----
$ mvn spring-boot:run -Dspring-boot.run.arguments="property1 'property2=Hello World'"
----

Các active profiles được dùng cho một application cụ thể có thể được chỉ định bằng argument `profiles`.

Configuration sau enable các profiles `local` và `dev`:

[source,xml,indent=0,subs="verbatim,attributes"]
----
include::example$running/active-profiles-pom.xml[tags=active-profiles]
----

Các profiles cần enable cũng có thể được chỉ định trên command line; hãy bảo đảm phân tách chúng bằng comma như trong ví dụ sau:

[source,shell]

----
