[[aot]]
= Ahead-of-Time Processing

Spring AOT là process analyze application tại build-time và generate optimized version.
Đây là bước bắt buộc để chạy Spring `ApplicationContext` trong native image.

NOTE: Để xem overview support GraalVM Native Images trong Spring Boot, xem xref:reference:packaging/native-image/index.adoc[reference documentation].

Spring Boot Maven plugin cung cấp goal dùng thực hiện AOT processing trên cả application code và test code.

Điều này khác quan trọng so với regular Spring Boot application làm tại runtime.
Ví dụ nếu muốn opt-in hoặc opt-out một số feature, cần configure environment dùng tại build time.
Goal `process-aot` share một số property với xref:run.adoc[run goal] vì lý do này.

[[aot.processing-applications.using-the-native-profile]]
=== Dùng Native Profile

Nếu dùng `spring-boot-starter-parent` làm `parent` của project, profile `native` có thể streamline các step cần để build native image.

Profile `native` configure:

* Execution `process-aot` khi Spring Boot Maven Plugin apply trên project.
* Suitable setting để xref:build-image.adoc[build-image] generate native image.
* Sensible default cho {url-native-build-tools-docs-maven-plugin}[Native Build Tools Maven Plugin], đặc biệt:
** Đảm bảo plugin dùng raw classpath, không phải main jar file vì nó không hiểu repackaged jar format.
** Validate suitable GraalVM version available.
** Download third-party reachability metadata.

[WARNING]
====
Dùng raw classpath nghĩa là native image không biết generated `MANIFEST.MF`.
Nếu cần read content manifest trong native image, ví dụ lấy implementation version của application, configure option `classesDirectory` để dùng regular jar.
====

[[aot.processing-tests]]
== Processing Tests

AOT engine có thể apply cho JUnit 5 test dùng Spring Test Context Framework.
Các test được AOT engine process rồi execute trong native image.

NOTE: Test không process khi regular test skip bằng property `maven.test.skip`.

Giống <<aot.processing-applications.using-the-native-profile,production code>>, `spring-boot-starter-parent` define profile `nativeTest` dùng streamline step cần execute test trong native image.

Profile `nativeTest` configure:

* Execution `process-test-aot` khi Spring Boot Maven Plugin apply trên project.
* Execution `test` khi {url-native-build-tools-docs-maven-plugin}[Native Build Tools Maven Plugin] apply.
Execution define sensible default, đặc biệt:
** Đảm bảo plugin dùng raw classpath, không phải main jar file vì không hiểu repackaged jar format.
** Validate suitable GraalVM version available.
** Download third-party reachability metadata.

Để dùng profile `nativeTest`, module đại diện application nên define hai plugin:

include::example$aot-native/pom.xml[tags=aot-native]
----

[source,shell]

$ mvn test -PnativeTest
----
