= Các application property deprecated

Các property deprecated sau có thể được chỉ định trong file `application.properties`, trong file `application.yaml`, hoặc dưới dạng command line switch.
Việc hỗ trợ các property này sẽ bị loại bỏ trong một release tương lai và bạn nên migrate khỏi chúng.

[TIP]
====
Spring Boot bao gồm tool `spring-boot-properties-migrator` hữu ích giúp bạn migrate khỏi các property deprecated.
Để sử dụng tool migrate property, thêm dependency sau vào project:

[tabs]
======
Maven::
+
[source,xml]
----
<dependency>
	<groupId>org.springframework.boot</groupId>
	<artifactId>spring-boot-properties-migrator</artifactId>
	<scope>runtime</scope>
</dependency>
----
Gradle::
+
[source,gradle]
----
runtimeOnly("org.springframework.boot:spring-boot-properties-migrator")
----
======

Sau khi thêm dependency vào project, tool không chỉ phân tích environment của application và in diagnostics lúc startup, mà còn tạm thời migrate các property tại runtime giúp bạn.

Hãy nhớ remove dependency này khi migration hoàn tất.
====
