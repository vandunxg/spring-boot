= Jersey



[[howto.jersey.spring-security]]
== Bảo mật các endpoint Jersey bằng Spring Security

Spring Security có thể được dùng để bảo mật một web application dựa trên Jersey, gần như tương tự cách dùng nó để bảo mật một web application dựa trên Spring MVC.
Tuy nhiên, nếu muốn dùng method-level security của Spring Security với Jersey, bạn phải configure Jersey dùng `setStatus(int)` thay vì `sendError(int)`.
Điều này ngăn Jersey commit response trước khi Spring Security có cơ hội thông báo authentication hoặc authorization failure cho client.

Property `jersey.config.server.response.setStatusOverSendError` phải được set thành `true` trên bean javadoc:org.glassfish.jersey.server.ResourceConfig[] của application, như ví dụ sau:

[[howto.jersey.alongside-another-web-framework]]
== Dùng Jersey cùng một web framework khác

Để dùng Jersey cùng một web framework khác, chẳng hạn Spring MVC, cần configure Jersey để framework kia có thể xử lý các request mà Jersey không thể xử lý.
Trước tiên, configure Jersey dùng filter thay vì servlet bằng application property configprop:spring.jersey.type[] với value `filter`.
Tiếp theo, configure javadoc:org.glassfish.jersey.server.ResourceConfig[] để forward các request lẽ ra sẽ trả về 404, như ví dụ sau.
