[[howto.nosql.jedis-instead-of-lettuce]]
== Sử dụng Jedis thay cho Lettuce

Mặc định, Spring Boot starter (`spring-boot-starter-data-redis`) sử dụng https://github.com/redis/lettuce/[Lettuce].
Bạn cần exclude dependency đó và include dependency https://github.com/redis/jedis/[Jedis] thay thế.
Spring Boot quản lý cả hai dependency này, cho phép bạn chuyển sang Jedis mà không cần chỉ định version.

Ví dụ sau cho thấy cách thực hiện trong Maven:

[source,xml]
----
<dependency>
	<groupId>org.springframework.boot</groupId>
	<artifactId>spring-boot-starter-data-redis</artifactId>
	<exclusions>
		<exclusion>
			<groupId>io.lettuce</groupId>
			<artifactId>lettuce-core</artifactId>
		</exclusion>
	</exclusions>
</dependency>
<dependency>
	<groupId>redis.clients</groupId>
	<artifactId>jedis</artifactId>
</dependency>
----

Ví dụ sau cho thấy cách thực hiện trong Gradle:

[source,gradle]
----
dependencies {
	implementation('org.springframework.boot:spring-boot-starter-data-redis') {
	    exclude group: 'io.lettuce', module: 'lettuce-core'
	}
	implementation 'redis.clients:jedis'
	// ...
}
----
