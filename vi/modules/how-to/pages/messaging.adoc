[[howto.messaging.disable-transacted-jms-session]]
== Disable Transacted JMS Session

Nếu JMS broker không hỗ trợ transacted session, bạn phải disable transaction support hoàn toàn.
Nếu tự tạo javadoc:org.springframework.jms.config.JmsListenerContainerFactory[], không cần làm gì vì mặc định nó không thể transacted.
Nếu muốn dùng javadoc:org.springframework.boot.jms.autoconfigure.DefaultJmsListenerContainerFactoryConfigurer[] để reuse default của Spring Boot, có thể disable transacted session như sau:

include-code::MyJmsConfiguration[]

Ví dụ trên override default factory và cũng nên apply cho mọi factory khác mà application định nghĩa, nếu có.
