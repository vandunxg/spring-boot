[[cli.installation]]
= Cài đặt CLI

Spring Boot CLI (Command-Line Interface) có thể cài thủ công bằng SDKMAN! (SDK Manager), hoặc bằng Homebrew hay MacPorts nếu bạn là người dùng OSX.
Xem xref:ROOT:installing.adoc#getting-started.installing.cli[] trong phần "`Getting Started`" để xem hướng dẫn cài đặt đầy đủ.
