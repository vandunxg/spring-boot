[[gradle-plugin]]
= Gradle Plugin

Spring Boot Gradle Plugin cung cấp Spring Boot support trong https://gradle.org[Gradle].
Nó cho phép package executable jar hoặc war archive, chạy Spring Boot application và dùng dependency management được cung cấp bởi `spring-boot-dependencies`.
Gradle plugin của Spring Boot yêu cầu Gradle 8.x (8.14 trở lên) hoặc 9.x và có thể dùng với {url-gradle-docs}/configuration_cache.html[configuration cache] của Gradle.

Ngoài user guide này, xref:api/java/index.html[API documentation] cũng available.
