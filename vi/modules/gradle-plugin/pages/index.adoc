[[gradle-plugin]]
= Gradle Plugin

Spring Boot Gradle Plugin cung cấp support cho Spring Boot trong https://gradle.org[Gradle].
Plugin này cho phép package executable jar hoặc war archive, chạy Spring Boot application và sử dụng dependency management do `spring-boot-dependencies` cung cấp.
Gradle plugin của Spring Boot yêu cầu Gradle 8.x (8.14 trở lên) hoặc 9.x và có thể dùng với {url-gradle-docs}/configuration_cache.html[configuration cache] của Gradle.

Ngoài user guide này, xref:api/java/index.html[API documentation] cũng có sẵn.
