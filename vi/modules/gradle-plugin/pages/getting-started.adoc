[[getting-started]]
= Getting Started

Để bắt đầu với plugin, cần apply nó vào project.

ifeval::["{build-type}" == "commercial"]
Plugin được publish tới Spring Commercial repository.
Cần configure build để access repository này.
Thông thường thực hiện qua local artifact repository mirror content của Spring Commercial repository.
Ngoài ra, dù không được khuyến nghị, Spring Commercial repository cũng có thể access trực tiếp.
Trong cả hai case, xem https://docs.vmware.com/en/Tanzu-Spring-Runtime/Commercial/Tanzu-Spring-Runtime/spring-enterprise-subscription.html[Tanzu Spring Runtime documentation] để biết thêm.

Khi access Spring Commercial repository đã configure trong `settings.gradle` hoặc `settings.gradle.kts`, plugin có thể apply bằng block `plugins`:

Khi apply riêng lẻ, plugin chỉ thay đổi ít thứ trong project.
Thay vào đó plugin detect khi một số plugin khác được apply và react tương ứng.
Ví dụ khi `java` plugin apply, task build executable jar được auto-configure.
Typical Spring Boot project tối thiểu apply {url-gradle-docs-groovy-plugin}[`groovy`], {url-gradle-docs-java-plugin}[`java`] hoặc {url-kotlin-docs-kotlin-plugin}[`org.jetbrains.kotlin.jvm`], đồng thời dùng {url-dependency-management-plugin-site}[`io.spring.dependency-management`] hoặc native bom support của Gradle cho dependency management.
