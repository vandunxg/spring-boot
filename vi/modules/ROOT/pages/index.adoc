= Spring Boot

Spring Boot giúp bạn tạo các ứng dụng dựa trên Spring độc lập, sẵn sàng cho production và có thể chạy trực tiếp.
Chúng tôi đưa ra những lựa chọn mặc định có chủ đích cho Spring platform và các thư viện bên thứ ba, giúp bạn bắt đầu thuận tiện nhất.
Hầu hết ứng dụng Spring Boot chỉ cần rất ít cấu hình Spring.

Bạn có thể dùng Spring Boot để tạo các ứng dụng Java khởi động bằng `java -jar` hoặc deploy theo cách truyền thống dưới dạng war.

Các mục tiêu chính của chúng tôi là:

* Giúp việc bắt đầu phát triển với Spring nhanh hơn đáng kể và dễ tiếp cận với mọi người.
* Cung cấp các lựa chọn mặc định có chủ đích ngay từ đầu, nhưng nhanh chóng nhường quyền kiểm soát khi yêu cầu bắt đầu khác với mặc định.
* Cung cấp nhiều tính năng non-functional phổ biến trong nhiều loại dự án (chẳng hạn embedded server, security, metrics, health check và externalized configuration).
* Hoàn toàn không sinh code (khi không nhắm tới native image) và không yêu cầu cấu hình XML.
