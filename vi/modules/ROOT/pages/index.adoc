= Spring Boot

Spring Boot giúp bạn tạo các ứng dụng Spring-based, stand-alone, production-grade mà bạn có thể chạy.
Chúng tôi có cách tiếp cận opinionated với Spring platform và các thư viện bên thứ ba, giúp bạn bắt đầu với ít phiền toái nhất.
Hầu hết ứng dụng Spring Boot chỉ cần rất ít cấu hình Spring.

Bạn có thể dùng Spring Boot để tạo các ứng dụng Java khởi động bằng `java -jar` hoặc deploy war theo cách truyền thống.

Các mục tiêu chính của chúng tôi là:

* Cung cấp trải nghiệm getting-started nhanh hơn đáng kể và dễ tiếp cận hơn cho mọi hoạt động phát triển Spring.
* Đưa ra opinionated defaults ngay từ đầu, nhưng nhanh chóng không can thiệp khi requirements bắt đầu khác với defaults.
* Cung cấp nhiều tính năng non-functional phổ biến trong nhiều loại dự án (chẳng hạn embedded server, security, metrics, health check và externalized configuration).
* Hoàn toàn không có code generation (khi không nhắm tới native image) và không yêu cầu cấu hình XML.
