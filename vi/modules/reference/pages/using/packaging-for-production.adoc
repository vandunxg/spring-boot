[[using.packaging-for-production]]
= Đóng gói ứng dụng cho production

Khi ứng dụng Spring Boot đã sẵn sàng để deploy lên production, có nhiều lựa chọn để đóng gói và tối ưu
ứng dụng.
Xem phần xref:packaging/index.adoc[] trong tài liệu để tìm hiểu các tính năng này.

Để có thêm các tính năng "production ready" như health, auditing và các endpoint REST hoặc JMX cho metrics, hãy cân nhắc thêm `spring-boot-actuator`.
Xem xref:how-to:actuator.adoc[] để biết chi tiết.
