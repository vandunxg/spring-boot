[[messaging.jms]]
= JMS

Interface javadoc:jakarta.jms.ConnectionFactory[] cung cấp cách chuẩn để tạo javadoc:jakarta.jms.Connection[] nhằm tương tác với JMS broker.
Mặc dù Spring cần javadoc:jakarta.jms.ConnectionFactory[] để làm việc với JMS, nhìn chung bạn không cần dùng trực tiếp mà có thể dựa vào các messaging abstraction cấp cao hơn.
(Xem {url-spring-framework-docs}/integration/jms.html[phần liên quan] trong Spring Framework reference documentation.)
Spring Boot cũng auto-configure infrastructure cần thiết để gửi và nhận message.

[[messaging.jms.activemq]]
== Hỗ trợ ActiveMQ "Classic"

Khi https://activemq.apache.org/components/classic[ActiveMQ "Classic"] có trên classpath, Spring Boot có thể cấu hình javadoc:jakarta.jms.ConnectionFactory[].
Nếu broker có mặt, embedded broker tự động được start và cấu hình, miễn là không có broker URL được chỉ định và embedded broker không bị disable.

NOTE: Nếu dùng `spring-boot-starter-activemq`, các dependency cần để kết nối ActiveMQ "Classic" cùng Spring infrastructure tích hợp JMS được cung cấp.
Thêm `org.apache.activemq:activemq-broker` cho phép dùng embedded broker.

ActiveMQ "Classic" configuration được điều khiển bởi external property trong `+spring.activemq.*+`.

Nếu `activemq-broker` có trên classpath, ActiveMQ "Classic" được auto-configure dùng https://activemq.apache.org/vm-transport-reference.html[VM transport], khởi động broker embedded trong cùng JVM.

Có thể disable embedded broker:

[configprops,yaml]
----
spring:
  activemq:
    embedded:
      enabled: false
----

Embedded broker cũng bị disable nếu cấu hình broker URL:

[configprops,yaml]
----
spring:
  activemq:
    broker-url: "tcp://192.168.1.210:9876"
    user: "admin"
    password: "secret"
----

Nếu muốn kiểm soát hoàn toàn embedded broker, xem https://activemq.apache.org/how-do-i-embed-a-broker-inside-a-connection.html[ActiveMQ "Classic" documentation].

Mặc định javadoc:org.springframework.jms.connection.CachingConnectionFactory[] wrap native javadoc:jakarta.jms.ConnectionFactory[] với setting hợp lý, có thể điều khiển qua `+spring.jms.*+`:

[configprops,yaml]
----
spring:
  jms:
    cache:
      session-cache-size: 5
----

Nếu muốn native pooling, thêm dependency `org.messaginghub:pooled-jms` và cấu hình javadoc:org.messaginghub.pooled.jms.JmsPoolConnectionFactory[]:

[configprops,yaml]
----
spring:
  activemq:
    pool:
      enabled: true
      max-connections: 50
----

TIP: Xem javadoc:org.springframework.boot.activemq.autoconfigure.ActiveMQProperties[] để biết thêm option.
Bạn cũng có thể register nhiều bean implement javadoc:org.springframework.boot.activemq.autoconfigure.ActiveMQConnectionFactoryCustomizer[] cho customization nâng cao.

Mặc định ActiveMQ "Classic" tạo destination nếu chưa tồn tại, vì vậy destination được resolve theo name đã cung cấp.

[[messaging.jms.artemis]]
== Hỗ trợ ActiveMQ Artemis

Spring Boot có thể auto-configure javadoc:jakarta.jms.ConnectionFactory[] khi phát hiện https://activemq.apache.org/components/artemis/[ActiveMQ Artemis] trên classpath.
Nếu broker có mặt, embedded broker tự động start và configure, trừ khi property mode được đặt rõ.
Các mode được hỗ trợ là `embedded` và `native`.
`embedded` yêu cầu embedded broker có trên classpath; `native` kết nối broker qua transport protocol `netty`.
Với `native`, Spring Boot cấu hình javadoc:jakarta.jms.ConnectionFactory[] kết nối broker trên local machine bằng default setting.

NOTE: Nếu dùng `spring-boot-starter-artemis`, các dependency cần để kết nối existing ActiveMQ Artemis cùng Spring infrastructure tích hợp JMS được cung cấp.
Thêm `org.apache.activemq:artemis-jakarta-server` để dùng embedded mode.

ActiveMQ Artemis configuration được điều khiển bởi `+spring.artemis.*+`:

[configprops,yaml]
----
spring:
  artemis:
    mode: native
    broker-url: "tcp://192.168.1.210:9876"
    user: "admin"
    password: "secret"
----

Khi embed broker, có thể chọn bật persistence và liệt kê destination cần có.
Có thể dùng comma-separated list với default option, hoặc định nghĩa bean javadoc:org.apache.activemq.artemis.jms.server.config.JMSQueueConfiguration[] hay javadoc:org.apache.activemq.artemis.jms.server.config.TopicConfiguration[] cho advanced queue/topic configuration.

Mặc định javadoc:org.springframework.jms.connection.CachingConnectionFactory[] wrap native javadoc:jakarta.jms.ConnectionFactory[] với setting qua `+spring.jms.*+`:

[configprops,yaml]
----
spring:
  jms:
    cache:
      session-cache-size: 5
----

Nếu muốn native pooling, thêm `org.messaginghub:pooled-jms` và cấu hình:

[configprops,yaml]
----
spring:
  artemis:
    pool:
      enabled: true
      max-connections: 50
----

Xem javadoc:org.springframework.boot.artemis.autoconfigure.ArtemisProperties[] để biết thêm option.

Không có JNDI lookup; destination được resolve theo name, dùng attribute `name` trong ActiveMQ Artemis configuration hoặc name từ configuration.

[[messaging.jms.jndi]]
== Sử dụng JNDI ConnectionFactory

Nếu application chạy trong application server, Spring Boot thử locate JMS javadoc:jakarta.jms.ConnectionFactory[] bằng JNDI.
Mặc định kiểm tra `java:/JmsXA` và `java:/XAConnectionFactory`.
Có thể dùng configprop:spring.jms.jndi-name[] để chỉ định location khác:

[configprops,yaml]
----
spring:
  jms:
    jndi-name: "java:/MyConnectionFactory"
----

[[messaging.jms.receiving]]
== Nhận Message

Khi JMS infrastructure có mặt, bean có thể annotate javadoc:org.springframework.jms.annotation.JmsListener[format=annotation] để tạo listener endpoint.
Nếu chưa định nghĩa javadoc:org.springframework.jms.config.JmsListenerContainerFactory[], default factory được cấu hình tự động.
Nếu có bean javadoc:org.springframework.jms.support.destination.DestinationResolver[], javadoc:org.springframework.jms.support.converter.MessageConverter[] hoặc javadoc:jakarta.jms.ExceptionListener[], chúng tự động liên kết với default factory.

Trong hầu hết scenario, message listener container nên được cấu hình với native javadoc:jakarta.jms.ConnectionFactory[].
Như vậy mỗi listener container có connection riêng và chịu trách nhiệm hoàn toàn về local recovery.
Auto-configuration dùng javadoc:org.springframework.boot.jms.ConnectionFactoryUnwrapper[] để unwrap native connection factory từ auto-configured factory.

NOTE: Auto-configuration chỉ unwrap `CachedConnectionFactory`.

Mặc định default factory là transactional.
Nếu infrastructure có javadoc:org.springframework.transaction.jta.JtaTransactionManager[], nó được liên kết với listener container.
Nếu không, flag `sessionTransacted` được bật.
Trong trường hợp đó, có thể liên kết local data store transaction với xử lý incoming message bằng javadoc:org.springframework.transaction.annotation.Transactional[format=annotation] trên listener method.
Message chỉ được acknowledged sau khi local transaction hoàn tất.
Điều này cũng gồm response message gửi trên cùng JMS session.
