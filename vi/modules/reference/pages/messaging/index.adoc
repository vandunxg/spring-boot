[[messaging]]
= Messaging

Spring Framework cung cấp hỗ trợ toàn diện cho việc tích hợp với các messaging system, từ việc sử dụng đơn giản JMS API thông qua javadoc:org.springframework.jms.core.JmsClient[] đến một infrastructure hoàn chỉnh để nhận message async.
Spring AMQP cung cấp feature set tương tự cho Advanced Message Queuing Protocol.
Spring Boot cũng cung cấp các tùy chọn auto-configuration cho javadoc:org.springframework.amqp.rabbit.core.RabbitTemplate[] và RabbitMQ.
Spring WebSocket tích hợp sẵn hỗ trợ STOMP messaging, và Spring Boot hỗ trợ tính năng này thông qua các starter cùng một lượng nhỏ auto-configuration.
Spring Boot cũng hỗ trợ Apache Kafka và Apache Pulsar.
