[[messaging.amqp]]
= AMQP

Advanced Message Queuing Protocol (AMQP) là platform-neutral wire-level protocol cho message-oriented middleware.
Project Spring AMQP áp dụng core Spring concept vào việc phát triển messaging solution dựa trên AMQP.
Spring Boot cung cấp auto-configuration cho ba style AMQP khác nhau:

* xref:messaging/amqp.adoc#messaging.amqp.generic[Generic AMQP 1.0] (`spring-boot-starter-amqp`) — hỗ trợ AMQP 1.0 không phụ thuộc broker, dựa trên Qpid ProtonJ2 client library.
  Dùng khi portability giữa các broker tương thích AMQP 1.0 như ActiveMQ, Azure Service Bus hoặc RabbitMQ là quan trọng.
* xref:messaging/amqp.adoc#messaging.amqp.rabbitmq[RabbitMQ AMQP 1.0] (`spring-boot-starter-amqp-rabbitmq`) — support riêng cho RabbitMQ qua native https://github.com/rabbitmq/rabbitmq-amqp-java-client[RabbitMQ AMQP 1.0 Java client].
  Dùng khi application chỉ target RabbitMQ và muốn dùng AMQP 1.0.
* xref:messaging/amqp.adoc#messaging.amqp.rabbitmq09[RabbitMQ AMQP 0.9] (`spring-boot-starter-rabbitmq`) — RabbitMQ qua classic AMQP 0.9.1.
  Dùng cho integration RabbitMQ lâu đời và nhiều feature nhất, gồm Streams support.

[[messaging.amqp.generic]]
== Hỗ trợ Generic AMQP 1.0

AMQP 1.0 được nhiều broker và messaging service ngoài RabbitMQ hỗ trợ, gồm ActiveMQ, Azure Service Bus và các hệ thống khác.
Spring AMQP cung cấp {url-spring-amqp-docs}/amqp10-client.html[generic support cho AMQP 1.0] qua `org.springframework.amqp:spring-amqp-client`, dựa trên https://github.com/apache/qpid-protonj2/blob/main/protonj2-client/README.md[Qpid ProtonJ2 Client Library].

AMQP configuration được điều khiển bởi external property trong `+spring.amqp.*+`:

[configprops,yaml]
----
spring:
  amqp:
    host: "localhost"
    port: 5672
    username: "admin"
    password: "secret"
----

Để cấu hình javadoc:org.apache.qpid.protonj2.client.ConnectionOptions[connection option] của auto-configured javadoc:org.springframework.amqp.client.AmqpConnectionFactory[], định nghĩa bean javadoc:org.springframework.boot.amqp.autoconfigure.ConnectionOptionsCustomizer[].

[[messaging.amqp.rabbitmq]]
== Hỗ trợ RabbitMQ AMQP 1.0

Spring AMQP cung cấp {url-spring-amqp-docs}/rabbitmq-amqp-client.html[support riêng RabbitMQ cho AMQP 1.0] qua `org.springframework.amqp:spring-rabbitmq-client`.

RabbitMQ AMQP 1.0 configuration được điều khiển bởi external property trong `+spring.amqp.rabbitmq.*+`:

[configprops,yaml]
----
spring:
  amqp:
    rabbitmq:
      host: "localhost"
      port: 5672
      username: "admin"
      password: "secret"
----

Ngoài ra có thể dùng attribute `address`:

[configprops,yaml]
----
spring:
  amqp:
    rabbitmq:
      address: "amqp://admin:secret@localhost"
----

NOTE: Khi dùng address, property `host` và `port` bị bỏ qua.
Nếu address dùng scheme `amqps`, phải cấu hình xref:features/ssl.adoc#features.ssl.bundles[SSL bundle].

Xem javadoc:org.springframework.boot.amqp.rabbitmq.autoconfigure.AmqpRabbitProperties[] để biết thêm option.
Để cấu hình chi tiết lower-level của auto-configured javadoc:com.rabbitmq.client.amqp.Environment[], định nghĩa bean javadoc:org.springframework.boot.amqp.rabbitmq.autoconfigure.AmqpEnvironmentCustomizer[].

Nếu context có bean javadoc:com.rabbitmq.client.amqp.CredentialsProvider[], nó tự động được auto-configured Environment dùng.

[[messaging.amqp.rabbitmq09]]
== Hỗ trợ RabbitMQ AMQP 0.9

https://www.rabbitmq.com/[RabbitMQ] là lightweight, reliable, scalable và portable message broker dựa trên AMQP.
Spring dùng RabbitMQ để giao tiếp qua AMQP protocol.

RabbitMQ configuration được điều khiển bởi `+spring.rabbitmq.*+`:

[configprops,yaml]
----
spring:
  rabbitmq:
    host: "localhost"
    port: 5672
    username: "admin"
    password: "secret"
----

Hoặc dùng `addresses`:

[configprops,yaml]
----
spring:
  rabbitmq:
    addresses: "amqp://admin:secret@localhost"
----

NOTE: Khi dùng addresses, `host` và `port` bị bỏ qua.
Nếu address dùng `amqps`, SSL support tự động được bật.

Xem javadoc:org.springframework.boot.rabbitmq.autoconfigure.RabbitProperties[] để biết thêm option.
Để cấu hình lower-level detail của RabbitMQ javadoc:com.rabbitmq.client.ConnectionFactory[] dùng bởi Spring AMQP, định nghĩa bean javadoc:org.springframework.boot.rabbitmq.autoconfigure.ConnectionFactoryCustomizer[].

Nếu context có bean javadoc:org.springframework.amqp.rabbit.connection.ConnectionNameStrategy[], nó tự động được dùng để đặt tên connection tạo bởi auto-configured javadoc:org.springframework.amqp.rabbit.connection.CachingConnectionFactory[].

Để application-wide additive customization cho javadoc:org.springframework.amqp.rabbit.core.RabbitTemplate[], dùng bean javadoc:org.springframework.boot.rabbitmq.autoconfigure.RabbitTemplateCustomizer[].

TIP: Xem https://spring.io/blog/2010/06/14/understanding-amqp-the-protocol-used-by-rabbitmq/[Understanding AMQP, the protocol used by RabbitMQ].

Có thể enable retry để xử lý khi listener throw exception.
Mặc định javadoc:org.springframework.amqp.rabbit.retry.RejectAndDontRequeueRecoverer[] được dùng, nhưng có thể định nghĩa javadoc:org.springframework.amqp.rabbit.retry.MessageRecoverer[] riêng.
Khi retry hết, message bị reject và bị drop hoặc route tới dead-letter exchange nếu broker được cấu hình.
Mặc định retry bị disable.
Có thể customize javadoc:org.springframework.core.retry.RetryPolicy[] bằng bean javadoc:org.springframework.boot.rabbitmq.autoconfigure.RabbitListenerRetrySettingsCustomizer[].

IMPORTANT: Mặc định, nếu retry bị disable và listener throw exception, delivery được retry vô hạn.
Có thể đổi bằng hai cách: đặt `defaultRequeueRejected=false` để không redelivery, hoặc throw javadoc:org.springframework.amqp.AmqpRejectAndDontRequeueException[] để reject message.
Cách thứ hai là cơ chế được dùng khi retry được enable và đạt maximum delivery attempt.
