[[messaging.amqp]]
= AMQP

Advanced Message Queuing Protocol (AMQP) là một wire-level protocol, platform-neutral dành cho message-oriented middleware.
Project Spring AMQP áp dụng các core concept của Spring vào việc phát triển các messaging solution dựa trên AMQP.
Spring Boot cung cấp auto-configuration cho ba style AMQP khác nhau:

* xref:messaging/amqp.adoc#messaging.amqp.generic[Generic AMQP 1.0] (`spring-boot-starter-amqp`) — hỗ trợ AMQP 1.0 không phụ thuộc broker, dựa trên Qpid ProtonJ2 client library.
  Dùng khi portability giữa các broker tương thích AMQP 1.0 như ActiveMQ, Azure Service Bus hoặc RabbitMQ là quan trọng.
* xref:messaging/amqp.adoc#messaging.amqp.rabbitmq[RabbitMQ AMQP 1.0] (`spring-boot-starter-amqp-rabbitmq`) — support dành riêng cho RabbitMQ qua native https://github.com/rabbitmq/rabbitmq-amqp-java-client[RabbitMQ AMQP 1.0 Java client].
  Dùng khi application chỉ target RabbitMQ và muốn sử dụng AMQP 1.0 protocol.
* xref:messaging/amqp.adoc#messaging.amqp.rabbitmq09[RabbitMQ AMQP 0.9] (`spring-boot-starter-rabbitmq`) — hỗ trợ RabbitMQ qua classic AMQP 0.9.1 protocol.
  Dùng cho integration RabbitMQ established nhất và nhiều feature nhất, gồm cả Streams support.



[[messaging.amqp.generic]]
== Hỗ trợ Generic AMQP 1.0

AMQP 1.0 được nhiều broker và messaging service ngoài RabbitMQ hỗ trợ, gồm ActiveMQ, Azure Service Bus và các hệ thống khác.
Spring AMQP cung cấp {url-spring-amqp-docs}/amqp10-client.html[generic support cho AMQP 1.0] qua `org.springframework.amqp:spring-amqp-client`, dựa trên https://github.com/apache/qpid-protonj2/blob/main/protonj2-client/README.md[Qpid ProtonJ2 Client Library].

AMQP configuration được điều khiển bởi external configuration properties trong `+spring.amqp.*+`.
Ví dụ, bạn có thể khai báo cấu hình sau:

[configprops,yaml]
----
spring:
  amqp:
    host: "localhost"
    port: 5672
    username: "admin"
    password: "secret"
----

Để cấu hình javadoc:org.apache.qpid.protonj2.client.ConnectionOptions[connection options] của auto-configured javadoc:org.springframework.amqp.client.AmqpConnectionFactory[], định nghĩa một bean javadoc:org.springframework.boot.amqp.autoconfigure.ConnectionOptionsCustomizer[].

[[messaging.amqp.rabbitmq]]
== Hỗ trợ RabbitMQ AMQP 1.0

Spring AMQP cung cấp {url-spring-amqp-docs}/rabbitmq-amqp-client.html[support riêng cho RabbitMQ đối với AMQP 1.0] qua `org.springframework.amqp:spring-rabbitmq-client`.

RabbitMQ AMQP 1.0 configuration được điều khiển bởi external configuration properties trong `+spring.amqp.rabbitmq.*+`.
Ví dụ, bạn có thể khai báo section sau trong `application.properties`:

[configprops,yaml]
----
spring:
  amqp:
    rabbitmq:
      host: "localhost"
      port: 5672
      username: "admin"
      password: "secret"
----

Ngoài ra, bạn có thể cấu hình cùng connection bằng attribute `address`:

[configprops,yaml]
----
spring:
  amqp:
    rabbitmq:
      address: "amqp://admin:secret@localhost"
----

NOTE: Khi chỉ định address theo cách này, các property `host` và `port` sẽ bị bỏ qua.
Nếu address sử dụng scheme `amqps`, phải cấu hình một xref:features/ssl.adoc#features.ssl.bundles[SSL bundle].

Xem javadoc:org.springframework.boot.amqp.rabbitmq.autoconfigure.AmqpRabbitProperties[] để biết thêm các property-based configuration option được hỗ trợ.
Để cấu hình các lower-level detail của javadoc:com.rabbitmq.client.amqp.Environment[] đã được auto-configure, định nghĩa một bean javadoc:org.springframework.boot.amqp.rabbitmq.autoconfigure.AmqpEnvironmentCustomizer[].

Nếu một bean javadoc:com.rabbitmq.client.amqp.CredentialsProvider[] tồn tại trong context, bean đó sẽ tự động được auto-configured javadoc:com.rabbitmq.client.amqp.Environment[] sử dụng.

[[messaging.amqp.rabbitmq09]]
== Hỗ trợ RabbitMQ AMQP 0.9

https://www.rabbitmq.com/[RabbitMQ] là một lightweight, reliable, scalable và portable message broker dựa trên AMQP protocol.
Spring sử dụng RabbitMQ để giao tiếp qua AMQP protocol.

RabbitMQ configuration được điều khiển bởi external configuration properties trong `+spring.rabbitmq.*+`.
Ví dụ, bạn có thể khai báo section sau trong `application.properties`:

[configprops,yaml]
----
spring:
  rabbitmq:
    host: "localhost"
    port: 5672
    username: "admin"
    password: "secret"
----

Ngoài ra, bạn có thể cấu hình cùng connection bằng attribute `addresses`:

[configprops,yaml]
----
spring:
  rabbitmq:
    addresses: "amqp://admin:secret@localhost"
----

NOTE: Khi chỉ định addresses theo cách này, các property `host` và `port` sẽ bị bỏ qua.
Nếu address sử dụng protocol `amqps`, SSL support sẽ được enable tự động.

Xem javadoc:org.springframework.boot.rabbitmq.autoconfigure.RabbitProperties[] để biết thêm các property-based configuration option được hỗ trợ.
Để cấu hình các lower-level detail của RabbitMQ javadoc:com.rabbitmq.client.ConnectionFactory[] được Spring AMQP sử dụng, định nghĩa một bean javadoc:org.springframework.boot.rabbitmq.autoconfigure.ConnectionFactoryCustomizer[].

Nếu một bean javadoc:org.springframework.amqp.rabbit.connection.ConnectionNameStrategy[] tồn tại trong context, bean đó sẽ tự động được dùng để đặt tên cho các connection được tạo bởi javadoc:org.springframework.amqp.rabbit.connection.CachingConnectionFactory[] đã được auto-configure.

Để thực hiện additive customization ở phạm vi application cho javadoc:org.springframework.amqp.rabbit.core.RabbitTemplate[], sử dụng một bean javadoc:org.springframework.boot.rabbitmq.autoconfigure.RabbitTemplateCustomizer[].

TIP: Xem https://spring.io/blog/2010/06/14/understanding-amqp-the-protocol-used-by-rabbitmq/[Understanding AMQP, the protocol used by RabbitMQ] để biết thêm chi tiết.

Bạn có thể enable retry để xử lý các tình huống listener throw exception.
Mặc định, javadoc:org.springframework.amqp.rabbit.retry.RejectAndDontRequeueRecoverer[] được sử dụng, nhưng bạn có thể định nghĩa một javadoc:org.springframework.amqp.rabbit.retry.MessageRecoverer[] của riêng mình.
Khi retry đã hết, message bị reject và bị drop hoặc được route tới dead-letter exchange nếu broker được cấu hình để làm vậy.
Retry bị disable theo mặc định.
Bạn cũng có thể customize javadoc:org.springframework.core.retry.RetryPolicy[] programmatically bằng cách khai báo một bean javadoc:org.springframework.boot.rabbitmq.autoconfigure.RabbitListenerRetrySettingsCustomizer[].

IMPORTANT: Theo mặc định, nếu retry bị disable và listener throw exception, delivery sẽ được retry vô hạn.
Bạn có thể thay đổi hành vi này theo hai cách: đặt property `defaultRequeueRejected` thành `false` để không thực hiện redelivery nào, hoặc throw một javadoc:org.springframework.amqp.AmqpRejectAndDontRequeueException[] để báo hiệu rằng message phải bị reject.
Cách thứ hai là cơ chế được sử dụng khi retry được enable và đã đạt đến số delivery attempt tối đa.
