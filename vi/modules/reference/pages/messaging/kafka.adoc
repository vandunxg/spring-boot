[[messaging.kafka]]
= Hỗ trợ Apache Kafka

https://kafka.apache.org/[Apache Kafka] được hỗ trợ bằng cách cung cấp auto-configuration cho project `spring-kafka`.

Kafka configuration được kiểm soát bởi external configuration properties trong `spring.kafka.*`.
Ví dụ, có thể khai báo section sau trong `application.properties`:

[configprops,yaml]
----
spring:
  kafka:
    bootstrap-servers: "localhost:9092"
    consumer:
      group-id: "myGroup"
----

TIP: Để tạo topic khi startup, thêm bean có type javadoc:org.apache.kafka.clients.admin.NewTopic[].
Nếu topic đã tồn tại, bean bị bỏ qua.

Xem javadoc:org.springframework.boot.kafka.autoconfigure.KafkaProperties[] để biết thêm các option được hỗ trợ.

[[messaging.kafka.streams]]
== Kafka Streams

Spring for Apache Kafka cung cấp factory bean để tạo object javadoc:org.apache.kafka.streams.StreamsBuilder[] và quản lý lifecycle của các stream.
Spring Boot auto-configure bean javadoc:org.springframework.kafka.config.KafkaStreamsConfiguration[] cần thiết, miễn là `kafka-streams` có trên classpath và Kafka Streams được enable bằng annotation javadoc:org.springframework.kafka.annotation.EnableKafkaStreams[format=annotation].

Việc enable Kafka Streams có nghĩa là application id và bootstrap servers phải được thiết lập.
Application id có thể được cấu hình bằng `spring.kafka.streams.application-id`, mặc định là `spring.application.name` nếu chưa được thiết lập.
Bootstrap servers có thể được thiết lập globally hoặc chỉ được override riêng cho streams.

Có một số property bổ sung thông qua các property chuyên dụng; các Kafka property tùy ý khác có thể được thiết lập bằng namespace `spring.kafka.streams.properties`.
Xem thêm xref:messaging/kafka.adoc#messaging.kafka.additional-properties[] để biết thêm thông tin.

Để dùng factory bean, wire javadoc:org.apache.kafka.streams.StreamsBuilder[] vào javadoc:org.springframework.context.annotation.Bean[format=annotation] như trong ví dụ sau:

include-code::MyKafkaStreamsConfiguration[]

Mặc định, các stream do javadoc:org.apache.kafka.streams.StreamsBuilder[] quản lý sẽ tự động được start.
Có thể customize hành vi này bằng property configprop:spring.kafka.streams.auto-startup[].

TIP: Bạn cũng có thể register số lượng bean tùy ý implement javadoc:org.springframework.kafka.config.StreamsBuilderFactoryBeanConfigurer[] để thực hiện các customization nâng cao hơn.



[[messaging.kafka.additional-properties]]
== Kafka Property bổ sung

Các property được auto-configuration hỗ trợ được liệt kê trong section xref:appendix:application-properties/index.adoc#appendix.application-properties.integration[Integration Properties] của Appendix.
Lưu ý rằng phần lớn các property này (dạng hyphen hoặc camelCase) map trực tiếp tới các dotted property của Apache Kafka.
Xem tài liệu Apache Kafka để biết chi tiết.

Các property không chứa client type (`producer`, `consumer`, `admin`, hoặc `streams`) trong tên được xem là common và áp dụng cho tất cả client.
Nếu cần, hầu hết các common property này có thể được override cho một hoặc nhiều client type.

Apache Kafka đánh dấu property importance HIGH, MEDIUM hoặc LOW.
Spring Boot auto-configuration hỗ trợ tất cả property có importance HIGH, một số property MEDIUM và LOW được chọn, cùng mọi property không có default value.

Chỉ một subset các property được Kafka hỗ trợ có sẵn trực tiếp thông qua class javadoc:org.springframework.boot.kafka.autoconfigure.KafkaProperties[].
Nếu muốn cấu hình từng client type bằng các property bổ sung chưa được hỗ trợ trực tiếp, hãy sử dụng các property sau:

[configprops,yaml]
----
spring:
  kafka:
    properties:
      "[prop.one]": "first"
    admin:
      properties:
        "[prop.two]": "second"
    consumer:
      properties:
        "[prop.three]": "third"
    producer:
      properties:
        "[prop.four]": "fourth"
    streams:
      properties:
        "[prop.five]": "fifth"
----

Cấu hình này đặt common Kafka property `prop.one` thành `first` (áp dụng cho producers, consumers, admins và streams), admin property `prop.two` thành `second`, consumer property `prop.three` thành `third`, producer property `prop.four` thành `fourth` và streams property `prop.five` thành `fifth`.

Bạn cũng có thể cấu hình Spring Kafka javadoc:org.springframework.kafka.support.serializer.JacksonJsonDeserializer[] như sau:

[configprops,yaml]
----
spring:
  kafka:
    consumer:
      value-deserializer: "org.springframework.kafka.support.serializer.JacksonJsonDeserializer"
      properties:
        "[spring.json.value.default.type]": "com.example.Invoice"
        "[spring.json.trusted.packages]": "com.example.main,com.example.another"
----

Tương tự, bạn có thể disable behavior mặc định của javadoc:org.springframework.kafka.support.serializer.JacksonJsonSerializer[] là gửi type information trong header:

[configprops,yaml]
----
spring:
  kafka:
    producer:
      value-serializer: "org.springframework.kafka.support.serializer.JacksonJsonSerializer"
      properties:
        "[spring.json.add.type.headers]": false
----

IMPORTANT: Các property được thiết lập theo cách này sẽ override mọi configuration item được Spring Boot hỗ trợ rõ ràng.



[[messaging.kafka.embedded]]
== Test với Embedded Kafka

Spring for Apache Kafka cung cấp một cách thuận tiện để test các project với embedded Apache Kafka broker.
Để sử dụng feature này, annotate một test class bằng javadoc:org.springframework.kafka.test.context.EmbeddedKafka[format=annotation] từ module `spring-kafka-test`.
Để biết thêm thông tin, xem {url-spring-kafka-docs}/testing.html#ekb[reference manual] của Spring for Apache Kafka.

Để Spring Boot auto-configuration hoạt động với embedded Apache Kafka broker nói trên, cần remap một system property chứa các embedded broker address (được populate bởi javadoc:org.springframework.kafka.test.EmbeddedKafkaBroker[]) vào Spring Boot configuration property cho Apache Kafka.
Có một số cách để thực hiện việc này:

* Cung cấp một system property để map các embedded broker address vào configprop:spring.kafka.bootstrap-servers[] trong test class:

include-code::property/MyTest[tag=*]

* Cấu hình một property name trên annotation javadoc:org.springframework.kafka.test.context.EmbeddedKafka[format=annotation]:

include-code::annotation/MyTest[]

* Sử dụng một placeholder trong configuration properties:

[configprops,yaml]
----
spring:
  kafka:
    bootstrap-servers: "${spring.embedded.kafka.brokers}"
----
