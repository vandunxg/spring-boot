= Checkpoint and Restore với JVM

https://wiki.openjdk.org/display/crac/Main[Coordinated Restore at Checkpoint] (CRaC) là OpenJDK project định nghĩa Java API mới để checkpoint và restore application trên HotSpot JVM.
Nó dựa trên https://github.com/checkpoint-restore/criu[CRIU], project implement checkpoint/restore trên Linux.

Nguyên tắc: start application gần như bình thường nhưng dùng JDK hỗ trợ CRaC như https://bell-sw.com/pages/downloads/?package=jdk-crac[BellSoft Liberica JDK with CRaC] hoặc https://www.azul.com/downloads/?package=jdk-crac#zulu[Azul Zulu JDK with CRaC].
Sau đó, có thể sau workload làm warm JVM bằng cách execute common code path, trigger checkpoint qua API call, lệnh `jcmd`, HTTP endpoint hoặc mechanism khác.

Memory representation của JVM đang chạy, gồm trạng thái warm, được serialize xuống disk, cho phép restore nhanh sau đó, có thể trên machine khác với operating system và CPU architecture tương tự.
Process được restore giữ mọi capability của HotSpot JVM, gồm JIT optimization tiếp tục ở runtime.

Dựa trên nền tảng Spring Framework, Spring Boot hỗ trợ checkpoint/restore application và quản lý lifecycle của resource như socket, file và thread pool https://github.com/spring-projects/spring-lifecycle-smoke-tests/blob/ci/STATUS.adoc[trong phạm vi giới hạn].
Dependency khác và application code xử lý các resource này có thể cần lifecycle management bổ sung.

Chi tiết về hai mode ("on demand checkpoint/restore of a running application" và "automatic checkpoint/restore at startup"), cách enable và guideline xem {url-spring-framework-docs}/integration/checkpoint-restore.html[Spring Framework JVM Checkpoint Restore support documentation].
