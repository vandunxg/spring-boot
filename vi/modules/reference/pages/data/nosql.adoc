[[data.nosql.redis]]
== Redis

https://redis.io/[Redis] là cache, message broker và key-value store giàu tính năng.
Spring Boot cung cấp basic auto-configuration cho client https://github.com/redis/lettuce/[Lettuce] và https://github.com/redis/jedis/[Jedis], cùng abstraction phía trên do https://github.com/spring-projects/spring-data-redis[Spring Data Redis] cung cấp.

Starter `spring-boot-starter-data-redis` gom dependency thuận tiện.
Mặc định nó dùng https://github.com/redis/lettuce/[Lettuce].
Starter này hỗ trợ cả traditional và reactive application.

TIP: Chúng tôi cũng cung cấp `spring-boot-starter-data-redis-reactive` để nhất quán với các store khác có reactive support.

=== Kết nối Redis

Bạn có thể inject auto-configured javadoc:org.springframework.data.redis.connection.RedisConnectionFactory[], javadoc:org.springframework.data.redis.core.StringRedisTemplate[] hoặc javadoc:org.springframework.data.redis.core.RedisTemplate[] như Spring Bean khác.
Listing sau minh họa ví dụ về một bean như vậy:

include-code::MyBean[]

Mặc định instance cố kết nối Redis server tại `localhost:6379`.
Có thể chỉ định connection detail bằng `spring.data.redis.*`:

[configprops,yaml]
----
spring:
  data:
    redis:
      host: "localhost"
      port: 6379
      database: 0
      username: "user"
      password: "secret"
----

Bạn cũng có thể chỉ định URL Redis server trực tiếp.
Khi đặt URL, host, port, username và password property bị bỏ qua.
Ví dụ sau minh họa điều này:

[configprops,yaml]
----
spring:
  data:
    redis:
      url: "redis://user:secret@localhost:6379"
      database: 0
----

TIP: Có thể register nhiều bean javadoc:org.springframework.boot.data.redis.autoconfigure.LettuceClientConfigurationBuilderCustomizer[] để customization nâng cao.
javadoc:io.lettuce.core.resource.ClientResources[] cũng có thể customize bằng javadoc:org.springframework.boot.data.redis.autoconfigure.ClientResourcesBuilderCustomizer[].
Nếu dùng Jedis, có javadoc:org.springframework.boot.data.redis.autoconfigure.JedisClientConfigurationBuilderCustomizer[].

Ngoài ra có thể register bean javadoc:org.springframework.data.redis.connection.RedisStandaloneConfiguration[], javadoc:org.springframework.data.redis.connection.RedisSentinelConfiguration[], javadoc:org.springframework.data.redis.connection.RedisClusterConfiguration[] hoặc javadoc:org.springframework.data.redis.connection.RedisStaticMasterReplicaConfiguration[] để kiểm soát hoàn toàn configuration.

NOTE: master/replica không được Jedis hỗ trợ.

Nếu thêm bean riêng của bất kỳ auto-configured type nào, nó thay default, ngoại trừ javadoc:org.springframework.data.redis.core.RedisTemplate[] nơi exclusion dựa trên bean name `redisTemplate` chứ không phải type.

Mặc định pooled connection factory được auto-configure nếu `commons-pool2` có trên classpath.

Auto-configured javadoc:org.springframework.data.redis.connection.RedisConnectionFactory[] có thể dùng SSL:

[configprops,yaml]
----
spring:
  data:
    redis:
      ssl:
        enabled: true
----

Custom SSL trust material có thể cấu hình trong xref:features/ssl.adoc[SSL bundle] và áp dụng:

[configprops,yaml]
----
spring:
  data:
    redis:
      ssl:
        bundle: "example"
----

=== Kết nối MongoDB Database

Để access MongoDB database, có thể inject auto-configured javadoc:org.springframework.data.mongodb.MongoDatabaseFactory[].
Mặc định instance cố kết nối MongoDB server tại `mongodb://localhost/test`.
Ví dụ sau minh họa cách kết nối tới MongoDB database:

include-code::MyBean[]

Nếu tự định nghĩa javadoc:{url-mongodb-driver-sync-javadoc}/com.mongodb.client.MongoClient[], nó được dùng để auto-configure javadoc:org.springframework.data.mongodb.MongoDatabaseFactory[] phù hợp.

Auto-configured javadoc:{url-mongodb-driver-sync-javadoc}/com.mongodb.client.MongoClient[] được tạo bằng bean javadoc:{url-mongodb-driver-core-javadoc}/com.mongodb.MongoClientSettings[].
Nếu tự định nghĩa javadoc:{url-mongodb-driver-core-javadoc}/com.mongodb.MongoClientSettings[], bean đó được dùng nguyên trạng và property `spring.data.mongodb` bị bỏ qua.
Nếu không, javadoc:{url-mongodb-driver-core-javadoc}/com.mongodb.MongoClientSettings[] được auto-configure và áp dụng property `spring.data.mongodb`.
Trong cả hai trường hợp có thể khai báo một hoặc nhiều bean javadoc:org.springframework.boot.mongodb.autoconfigure.MongoClientSettingsBuilderCustomizer[] để fine-tune configuration javadoc:{url-mongodb-driver-core-javadoc}/com.mongodb.MongoClientSettings[].
Mỗi bean được gọi lần lượt với javadoc:{url-mongodb-driver-core-javadoc}/com.mongodb.MongoClientSettings$Builder[] dùng để build javadoc:{url-mongodb-driver-core-javadoc}/com.mongodb.MongoClientSettings[].

Có thể đặt configprop:spring.mongodb.uri[] để đổi URL và cấu hình replica set:

[configprops,yaml]
----
spring:
  mongodb:
    uri: "mongodb://user:secret@mongoserver1.example.com:27017,mongoserver2.example.com:23456/test"
----

Hoặc bạn có thể chỉ định connection detail bằng các property riêng lẻ.
Ví dụ, bạn có thể khai báo các setting sau trong `application.properties`:

[configprops,yaml]
----
spring:
  mongodb:
    host: "mongoserver1.example.com"
    port: 27017
    additional-hosts:
    - "mongoserver2.example.com:23456"
    database: "test"
    username: "user"
    password: "secret"
----

Auto-configured javadoc:{url-mongodb-driver-sync-javadoc}/com.mongodb.client.MongoClient[] có thể được cấu hình để dùng SSL khi giao tiếp với server bằng cách set các property như ví dụ sau:

[configprops,yaml]
----
spring:
  mongodb:
    uri: "mongodb://user:secret@mongoserver1.example.com:27017,mongoserver2.example.com:23456/test"
    ssl:
      enabled: true
----

Custom SSL trust material có thể cấu hình trong xref:features/ssl.adoc[SSL bundle] và áp dụng cho javadoc:{url-mongodb-driver-sync-javadoc}/com.mongodb.client.MongoClient[] như ví dụ sau:

[configprops,yaml]
----
spring:
  mongodb:
    uri: "mongodb://user:secret@mongoserver1.example.com:27017,mongoserver2.example.com:23456/test"
    ssl:
      bundle: "example"
----

[TIP]
====
Nếu configprop:spring.mongodb.port[] không được chỉ định, default `27017` được dùng.
Có thể bỏ dòng port trong ví dụ trước.

Cũng có thể chỉ định port trong host address bằng syntax `host:port`.
Format này nên dùng khi cần đổi port của entry `additional-hosts`.
====

TIP: Nếu không dùng Spring Data MongoDB, có thể inject bean javadoc:{url-mongodb-driver-sync-javadoc}/com.mongodb.client.MongoClient[] trực tiếp thay cho javadoc:org.springframework.data.mongodb.MongoDatabaseFactory[].
Nếu muốn kiểm soát hoàn toàn connection, có thể tự khai báo javadoc:org.springframework.data.mongodb.MongoDatabaseFactory[] hoặc javadoc:{url-mongodb-driver-sync-javadoc}/com.mongodb.client.MongoClient[] bean.

NOTE: Nếu dùng reactive driver, Netty là bắt buộc cho SSL.
Auto-configuration tự cấu hình factory nếu Netty có sẵn và factory chưa được customize.

[[data.nosql.elasticsearch]]
== Elasticsearch

https://www.elastic.co/products/elasticsearch[Elasticsearch] là open-source distributed RESTful search và analytics engine.
Spring Boot cung cấp basic auto-configuration cho Elasticsearch client.

Spring Boot hỗ trợ:

* Official low-level REST client
* Official Java API client
* javadoc:org.springframework.data.elasticsearch.client.elc.ReactiveElasticsearchClient[] từ Spring Data Elasticsearch

Spring Boot cung cấp starter `spring-boot-starter-data-elasticsearch`.

[[data.nosql.elasticsearch.connecting-using-rest]]
=== Kết nối Elasticsearch bằng REST Client

Elasticsearch có hai REST client để query cluster: https://www.elastic.co/docs/reference/elasticsearch/clients/java/transport/rest5-client/[low-level client] và https://www.elastic.co/docs/reference/elasticsearch/clients/java[Java API client].
Java API client từ module `co.elastic.clients:elasticsearch-java`, low-level client từ `co.elastic.clients:elasticsearch-rest5-client`.
Spring Boot cũng hỗ trợ reactive client từ `org.springframework.data:spring-data-elasticsearch`.
Mặc định client target `http://localhost:9200`.
Dùng `spring.elasticsearch.*` để tune:

[configprops,yaml]
----
spring:
  elasticsearch:
    uris: "https://search.example.com:9200"
    socket-timeout: "10s"
    username: "user"
    password: "secret"
----

[[data.nosql.elasticsearch.connecting-using-rest.restclient]]
==== Kết nối Elasticsearch bằng Rest5Client

Nếu `co.elastic.clients:elasticsearch-rest5-client` có trên classpath, Spring Boot auto-configure và register bean javadoc:co.elastic.clients.transport.rest5_client.low_level.Rest5Client[].
Để fine-tune có thể register nhiều bean javadoc:org.springframework.boot.elasticsearch.autoconfigure.Rest5ClientBuilderCustomizer[].
Để kiểm soát hoàn toàn client configuration, định nghĩa bean javadoc:co.elastic.clients.transport.rest5_client.low_level.Rest5ClientBuilder[].

javadoc:co.elastic.clients.transport.rest5_client.low_level.sniffer.Sniffer[] cũng có thể được auto-configure để tự động discover node từ Elasticsearch cluster và set lên javadoc:co.elastic.clients.transport.rest5_client.low_level.Rest5Client[].
Có thể tune:

[configprops,yaml]
----
spring:
  elasticsearch:
    restclient:
      sniffer:
        enabled: true
        interval: "10m"
        delay-after-failure: "30s"
----

[[data.nosql.elasticsearch.connecting-using-rest.javaapiclient]]
==== Kết nối Elasticsearch bằng ElasticsearchClient

Nếu dùng `spring-boot-starter-elasticsearch` hoặc thêm `co.elastic.clients:elasticsearch-java`, Spring Boot auto-configure bean javadoc:co.elastic.clients.elasticsearch.ElasticsearchClient[].

javadoc:co.elastic.clients.elasticsearch.ElasticsearchClient[] dùng transport phụ thuộc vào javadoc:co.elastic.clients.transport.rest5_client.low_level.Rest5Client[] đã mô tả ở trên.

Có thể định nghĩa javadoc:co.elastic.clients.transport.rest5_client.Rest5ClientOptions[] để kiểm soát thêm behavior transport.

[[data.nosql.cassandra]]
== Cassandra

https://cassandra.apache.org/[Cassandra] là open-source distributed database management system cho lượng data lớn trên nhiều commodity server.
Spring Boot cung cấp auto-configuration cho Cassandra và abstraction từ {url-spring-data-cassandra-site}[Spring Data Cassandra].
Starter `spring-boot-starter-data-cassandra` gom dependency.

[[data.nosql.cassandra.connecting]]
=== Kết nối Cassandra

Có thể inject auto-configured javadoc:org.springframework.data.cassandra.core.cql.CqlTemplate[], javadoc:org.springframework.data.cassandra.core.CassandraTemplate[] hoặc Cassandra `CqlSession`.
Property `spring.cassandra.*` dùng customize connection.
Thông thường cung cấp `keyspace-name`, `contact-points` và local datacenter:

[configprops,yaml]
----
spring:
  cassandra:
    keyspace-name: "mykeyspace"
    contact-points: "cassandrahost1:9042,cassandrahost2:9042"
    local-datacenter: "datacenter1"
----

Nếu port giống nhau cho mọi contact point, chỉ cần hostname:

[configprops,yaml]
----
spring:
  cassandra:
    keyspace-name: "mykeyspace"
    contact-points: "cassandrahost1,cassandrahost2"
    local-datacenter: "datacenter1"
----

TIP: Hai ví dụ tương đương vì default port là `9042`.
Nếu cần đổi port, dùng `spring.cassandra.port`.

Có thể bật SSL:

[configprops,yaml]
----
spring:
  cassandra:
    keyspace-name: "mykeyspace"
    contact-points: "cassandrahost1,cassandrahost2"
    local-datacenter: "datacenter1"
    ssl:
      enabled: true
----

Custom SSL trust material có thể cấu hình trong xref:features/ssl.adoc[SSL bundle] và áp dụng:

[configprops,yaml]
----
spring:
  cassandra:
    keyspace-name: "mykeyspace"
    contact-points: "cassandrahost1,cassandrahost2"
    local-datacenter: "datacenter1"
    ssl:
      bundle: "example"
----

[NOTE]
====
Cassandra driver có configuration infrastructure riêng load `application.conf` ở root classpath.

Spring Boot mặc định không tìm file này nhưng có thể load bằng `spring.cassandra.config`.

[[data.nosql.couchbase]]
== Couchbase

https://www.couchbase.com/[Couchbase] là open-source distributed multi-model NoSQL document database tối ưu cho interactive application.
Spring Boot cung cấp auto-configuration cho Couchbase và abstraction từ Spring Data Couchbase.
Có starter `spring-boot-starter-data-couchbase` và `spring-boot-starter-data-couchbase-reactive`.

[[data.nosql.couchbase.connecting]]
=== Kết nối Couchbase

Có thể lấy javadoc:com.couchbase.client.java.Cluster[] bằng cách thêm Couchbase SDK và configuration.
Property `spring.couchbase.*` dùng customize connection.
Thông thường bạn cung cấp https://docs.couchbase.com/dotnet-sdk/current/howtos/managing-connections.html[connection string] và credential để authentication. Basic authentication với username và password có thể cấu hình như ví dụ sau:

[configprops,yaml]
----
spring:
  couchbase:
    connection-string: "couchbase://192.168.1.123"
    username: "user"
    password: "secret"
----

https://docs.couchbase.com/server/current/manage/manage-security/configure-client-certificates.html[Client certificate] có thể dùng để authentication thay cho username và password.
Location và password của Java KeyStore chứa client certificate có thể cấu hình như ví dụ sau:

[configprops,yaml]
----
spring:
  couchbase:
    connection-string: "couchbase://192.168.1.123"
    env:
      ssl:
        enabled: true
    authentication:
      jks:
        location: "classpath:client.p12"
        password: "secret"
----

Certificate mã hóa PEM và private key có thể cấu hình như ví dụ sau:

[configprops,yaml]
----
spring:
  couchbase:
    connection-string: "couchbase://192.168.1.123"
    env:
      ssl:
        enabled: true
    authentication:
      pem:
        certificates: "classpath:client.crt"
        private-key: "classpath:client.key"
----

Có thể customize javadoc:com.couchbase.client.java.env.ClusterEnvironment[] setting.
Ví dụ, configuration sau đổi timeout để mở javadoc:com.couchbase.client.java.Bucket[] mới và bật hỗ trợ SSL bằng reference tới xref:features/ssl.adoc[SSL bundle] đã cấu hình:

[configprops,yaml]
----
spring:
  couchbase:
    env:
      timeouts:
        connect: "3s"
      ssl:
        bundle: "example"
----

TIP: Xem property `spring.couchbase.env.*`.
Để kiểm soát nhiều hơn, dùng bean javadoc:org.springframework.boot.couchbase.autoconfigure.ClusterEnvironmentBuilderCustomizer[].

[[data.nosql.ldap]]
== LDAP

https://en.wikipedia.org/wiki/Lightweight_Directory_Access_Protocol[LDAP] là open vendor-neutral industry standard application protocol để truy cập và duy trì distributed directory information service qua IP network.
Spring Boot cung cấp auto-configuration cho compliant LDAP server và embedded in-memory LDAP server từ https://ldap.com/unboundid-ldap-sdk-for-java/[UnboundID].

LDAP abstraction được cung cấp bởi Spring Data LDAP.
Starter `spring-boot-starter-data-ldap` gom dependency.

[[data.nosql.ldap.connecting]]
=== Kết nối LDAP Server

Để kết nối LDAP server, khai báo dependency `spring-boot-starter-data-ldap` hoặc `spring-ldap-core` rồi khai báo URL server:

[configprops,yaml]
----
spring:
  ldap:
    urls: "ldap://myserver:1235"
    username: "admin"
    password: "secret"
----

Có thể customize connection setting bằng `spring.ldap.base` và `spring.ldap.base-environment`.

javadoc:org.springframework.ldap.core.support.LdapContextSource[] được auto-configure từ các setting này.
Nếu bean javadoc:org.springframework.ldap.core.support.DirContextAuthenticationStrategy[] có sẵn, nó được liên kết với javadoc:org.springframework.ldap.core.support.LdapContextSource[].
Nếu cần customize, ví dụ dùng javadoc:org.springframework.ldap.pool2.factory.PooledContextSource[], vẫn có thể inject auto-configured javadoc:org.springframework.ldap.core.support.LdapContextSource[].
Đánh dấu custom javadoc:org.springframework.ldap.core.ContextSource[] là javadoc:org.springframework.context.annotation.Primary[format=annotation] để auto-configured javadoc:org.springframework.ldap.core.LdapTemplate[] dùng nó.

[[data.nosql.ldap.ssl]]
=== SSL

Để kết nối bằng LDAPS, cấu hình xref:features/ssl.adoc[SSL bundle] cần dùng qua property configprop:spring.ldap.ssl.bundle[], và dùng URL `ldaps://` trong property configprop:spring.ldap.urls[], như ví dụ sau:

[configprops,yaml]
----
spring:
  ldap:
    urls: "ldaps://myserver:636"
    ssl:
      bundle: "example"
----

Đặt configprop:spring.ldap.ssl.bundle[] cũng đổi default URL thành `ldaps://localhost:636`, nên configprop:spring.ldap.urls[] chỉ cần set khi kết nối tới host hoặc port khác.

NOTE: SSL chỉ hỗ trợ khi kết nối qua `ldaps://`. Bật SSL khi URL dùng `ldap://` sẽ fail startup.

Các property này không cấu hình StartTLS — cơ chế nâng cấp một connection `ldap://` thường thay vì dùng LDAPS, và vì vậy không thể kết hợp với SSL bundle.
Để dùng StartTLS, định nghĩa bean javadoc:org.springframework.ldap.core.support.DirContextAuthenticationStrategy[] như javadoc:org.springframework.ldap.core.support.DefaultTlsDirContextAuthenticationStrategy[] và set SSL socket factory.

Nếu cần hỗ trợ SSL mà không customize trust và key material, đặt property configprop:spring.ldap.ssl.enabled[] thành `true` thay vì cung cấp bundle.
Cách này dùng trust và key material mặc định của platform.

WARNING: Các property này chỉ áp dụng cho auto-configured javadoc:org.springframework.ldap.core.support.LdapContextSource[].
Nếu tự định nghĩa context source, phải tự cấu hình SSL.
Nếu tự định nghĩa bean javadoc:org.springframework.boot.ldap.autoconfigure.LdapConnectionDetails[], kể cả bean do `@ServiceConnection` đóng góp, auto-configured context source sẽ dùng SSL bundle mà bean đó cung cấp.
Một connection `ldaps://` chưa được cấp key hay trust material nào sẽ âm thầm dùng mặc định của platform thay vì fail.

TIP: Các property này cấu hình LDAP client và bị bỏ qua khi dùng embedded LDAP server.
Để bật SSL cho xref:data/nosql.adoc#data.nosql.ldap.embedded.ssl[embedded LDAP server], dùng property riêng configprop:spring.ldap.embedded.ssl.bundle[], property này cung cấp certificate và private key của server cũng như trust material của client.

[[data.nosql.ldap.embedded]]
=== Embedded In-memory LDAP Server

Để test, Spring Boot hỗ trợ auto-configuration in-memory LDAP server từ UnboundID.
Thêm dependency `com.unboundid:unboundid-ldapsdk` và khai báo configprop:spring.ldap.embedded.base-dn[]:

[configprops,yaml]
----
spring:
  ldap:
    embedded:
      base-dn: "dc=spring,dc=io"
----

[NOTE]
====
Có thể định nghĩa nhiều base-dn value; vì distinguished name thường chứa comma nên phải dùng notation đúng.

Trong YAML dùng list notation. Trong properties file, include index trong property name:

[configprops,yaml]
----
spring.ldap.embedded.base-dn:
- "dc=spring,dc=io"
- "dc=vmware,dc=com"
----
====

Mặc định server start trên random port và trigger regular LDAP support.

Nếu có `schema.ldif` trên classpath, nó được dùng initialize server.
Có thể dùng configprop:spring.ldap.embedded.ldif[] để load script từ resource khác.

Mặc định standard schema validate `LDIF` file.
Có thể disable validation bằng configprop:spring.ldap.embedded.validation.enabled[].
Nếu có custom attribute, dùng configprop:spring.ldap.embedded.validation.schema[].

Property `spring.ldap.embedded` cấu hình server, các property `spring.ldap` còn lại cấu hình client như mô tả trong xref:data/nosql.adoc#data.nosql.ldap[LDAP].
Mọi thứ mô tả chính connection đều lấy từ server, vì chỉ server mới xác định được một connection tới nó trông như thế nào:

* Client kết nối tới port và scheme server đang listen nên configprop:spring.ldap.urls[] bị bỏ qua.
* Client dùng credential từ configprop:spring.ldap.embedded.credential.username[] và configprop:spring.ldap.embedded.credential.password[].
* Client dùng SSL bundle từ configprop:spring.ldap.embedded.ssl.bundle[] nên `spring.ldap.ssl.*` bị bỏ qua.

Do đó production `spring.ldap` configuration không cần unset khi test với embedded server.
Các property còn lại như configprop:spring.ldap.base[], configprop:spring.ldap.referral[] và `spring.ldap.base-environment.*` vẫn được áp dụng.

TIP: Để cấu hình client khác đi, định nghĩa bean javadoc:org.springframework.boot.ldap.autoconfigure.LdapConnectionDetails[] của riêng bạn.
Auto-configured client khi đó dùng bean đó và bỏ qua URL, credential cũng như SSL bundle của embedded server.

[[data.nosql.ldap.embedded.ssl]]
==== SSL

In-memory LDAP server hỗ trợ SSL (LDAPS).
Để bật SSL, cấu hình xref:features/ssl.adoc[SSL bundle] qua configprop:spring.ldap.embedded.ssl.bundle[]:

[configprops,yaml]
----
spring:
  ldap:
    embedded:
      ssl:
        bundle: "example"
----

Bundle phải cung cấp server certificate và private key.

NOTE: LDAPS yêu cầu SSL bundle. Đặt configprop:spring.ldap.embedded.ssl.enabled[] mà không có configprop:spring.ldap.embedded.ssl.bundle[] sẽ fail startup.

Auto-configured client kết nối server qua `ldaps://` bằng cùng bundle, vì vậy trust material phải trust server certificate.

NOTE: Server quyết định có dùng TLS hay không và bundle nào bảo vệ connection.
Để client có SSL configuration riêng, định nghĩa javadoc:org.springframework.boot.ldap.autoconfigure.LdapConnectionDetails[] bean.
