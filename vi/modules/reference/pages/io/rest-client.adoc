[[io.rest-client]]
= Gọi REST Service

Spring Boot cung cấp nhiều cách thuận tiện để gọi remote REST service.
Nếu phát triển non-blocking reactive application và dùng Spring WebFlux, bạn có thể dùng javadoc:org.springframework.web.reactive.function.client.WebClient[].
Nếu thích imperative API, có thể dùng javadoc:org.springframework.web.client.RestClient[].

[[io.rest-client.webclient]]
== WebClient

Nếu Spring WebFlux có trên classpath, chúng tôi khuyến nghị dùng javadoc:org.springframework.web.reactive.function.client.WebClient[] để gọi remote REST service.
Interface javadoc:org.springframework.web.reactive.function.client.WebClient[] cung cấp functional-style API và hoàn toàn reactive.
Xem {url-spring-framework-docs}/web/webflux-webclient.html[phần javadoc:org.springframework.web.reactive.function.client.WebClient[] trong Spring Framework docs].

TIP: Nếu không viết reactive Spring WebFlux application, có thể dùng xref:io/rest-client.adoc#io.rest-client.restclient[`RestClient`] thay cho javadoc:org.springframework.web.reactive.function.client.WebClient[].
Nó cung cấp functional API tương tự nhưng imperative thay vì reactive.

Spring Boot tạo và pre-configure prototype bean javadoc:org.springframework.web.reactive.function.client.WebClient$Builder[].
Nên inject builder này vào component và dùng để tạo javadoc:org.springframework.web.reactive.function.client.WebClient[] instance.
Spring Boot cấu hình builder để share HTTP resource và phản ánh codec setup giống server (xem xref:web/reactive.adoc#web.reactive.webflux.httpcodecs[WebFlux HTTP codec auto-configuration]) cùng các thiết lập khác.

[[io.rest-client.webclient.runtime]]
=== WebClient Runtime

Spring Boot auto-detect javadoc:org.springframework.http.client.reactive.ClientHttpConnector[] dùng cho javadoc:org.springframework.web.reactive.function.client.WebClient[] dựa trên library trên classpath.
Thứ tự ưu tiên:

. Reactor Netty
. Jetty RS client
. Apache HttpClient
. JDK HttpClient

Nếu có nhiều client, client ưu tiên cao nhất được dùng.

Starter `spring-boot-starter-webflux` mặc định dependency `io.projectreactor.netty:reactor-netty`, gồm cả server và client implementation.
Nếu chọn Jetty làm reactive server, nên thêm `org.eclipse.jetty:jetty-reactive-httpclient`.
Dùng cùng technology cho server và client cho phép tự động share HTTP resource.

Developer có thể override resource configuration cho Jetty và Reactor Netty bằng custom bean javadoc:org.springframework.http.client.ReactorResourceFactory[] hoặc javadoc:org.springframework.http.client.reactive.JettyResourceFactory[]; configuration áp dụng cho cả client và server.

Nếu muốn override lựa chọn client, định nghĩa bean javadoc:org.springframework.http.client.reactive.ClientHttpConnector[] riêng.

Xem {url-spring-framework-docs}/web/webflux-webclient/client-builder.html[`WebClient` configuration option trong Spring Framework reference documentation].

[[io.rest-client.webclient.configuration]]
=== Global HTTP Connector Configuration

Nếu auto-detected javadoc:org.springframework.http.client.reactive.ClientHttpConnector[] không phù hợp, dùng configprop:spring.http.clients.reactive.connector[] để chọn connector cụ thể.
Ví dụ có Reactor Netty nhưng muốn dùng Jetty javadoc:org.eclipse.jetty.client.HttpClient[]:

[configprops,yaml]
----
spring:
  http:
    clients:
      reactive:
        connector: jetty
----

TIP: Cũng có thể dùng xref:io/rest-client.adoc#io.rest-client.global-configuration[global configuration property] áp dụng cho mọi HTTP client.

Với customization phức tạp hơn, dùng javadoc:org.springframework.boot.http.client.autoconfigure.reactive.ClientHttpConnectorBuilderCustomizer[] hoặc khai báo bean javadoc:org.springframework.boot.http.client.reactive.ClientHttpConnectorBuilder[] riêng khiến auto-configuration back off.
Điều này hữu ích khi cần customize internals của underlying HTTP library.

[[io.rest-client.webclient.customization]]
=== WebClient Customization

Có ba cách chính để customize javadoc:org.springframework.web.reactive.function.client.WebClient[] tùy phạm vi cần áp dụng.

Để scope hẹp nhất, inject auto-configured javadoc:org.springframework.web.reactive.function.client.WebClient$Builder[] rồi gọi method cần thiết.
Builder là stateful: mọi thay đổi trên builder ảnh hưởng tới client tạo sau đó.
Nếu tạo nhiều client từ cùng builder, có thể clone bằng `WebClient.Builder other = builder.clone();`.

Để application-wide additive customization cho mọi javadoc:org.springframework.web.reactive.function.client.WebClient$Builder[], khai báo bean javadoc:org.springframework.boot.webclient.WebClientCustomizer[] và thay đổi builder tại injection point.

Cuối cùng có thể dùng API gốc `WebClient.create()`.
Khi đó không có auto-configuration hoặc javadoc:org.springframework.boot.webclient.WebClientCustomizer[] được áp dụng.

[[io.rest-client.clienthttprequestfactory]]
== HTTP Client Detection cho RestClient

Spring Boot auto-detect HTTP client dùng với javadoc:org.springframework.web.client.RestClient[] dựa trên library trên classpath.
Thứ tự ưu tiên:

. Apache HttpClient
. Jetty HttpClient
. Reactor Netty HttpClient
. JDK client (`java.net.http.HttpClient`)
. Simple JDK client (`java.net.HttpURLConnection`)

Nếu có nhiều client và không có global configuration, client ưu tiên cao nhất được dùng.

[[io.rest-client.clienthttprequestfactory.configuration]]

[[io.rest-client.apiversioning]]
== API Versioning

Cả `WebClient` và `RestClient` hỗ trợ gọi remote HTTP API có version để API có thể evolve theo thời gian.
Thông thường version được gửi bằng HTTP header, query parameter hoặc URL path segment.

Có thể cấu hình API versioning qua method trên `WebClient.Builder` hoặc `RestClient.Builder`.

TIP: API versioning cũng được hỗ trợ server-side.
Xem xref:web/servlet.adoc#web.servlet.spring-mvc.api-versioning[Spring MVC] và xref:web/reactive.adoc#web.reactive.webflux.api-versioning[Spring WebFlux].

NOTE: Server-side API versioning configuration không được dùng để auto-configure client.
Client cần API versioning strategy, thường cho testing, phải cấu hình rõ ràng.

[[io.rest-client.httpservice.groups]]
=== Service Client Group

Hard-code absolute URL trong annotation javadoc:org.springframework.web.service.annotation.HttpExchange[format=annotation] thường không lý tưởng ở production.
Thay vào đó, nên dùng logical name và lookup URL từ property.

HTTP Service client hỗ trợ named group.
Một HTTP Service group là tập HTTP Service interface share common feature.

Ví dụ có thể định nghĩa group "echo" cho client gọi `https://echo.zuplo.io`.

[[io.rest-client.httpservice.properties]]
=== Configuration Property

Property cho HTTP Service được chỉ định dưới `spring.http.serviceclient.<group-name>`.

Có thể cấu hình:

* Base URL.
* Default header.
* API versioning.
* Redirect.
* Cookie handling.
* Connection và read timeout.
* SSL bundle.

TIP: Cũng có thể dùng xref:io/rest-client.adoc#io.rest-client.global-configuration[global configuration property].

Ví dụ dưới:

* Cấu hình mọi HTTP client dùng connect timeout 1 giây, trừ khi override.
* Cấu hình HTTP Service client trong group `echo`:
** Dùng base URL cụ thể.
** Connect timeout 1 giây.
** Read timeout 2 giây.

[configprops,yaml]
----
spring:
  http:
    clients:
      connect-timeout: 1s
    serviceclient:
      echo:
        base-url: "https://echo.zuplo.io"
        connect-timeout: 2s
        read-timeout: 2s
----

[[io.rest-client.global-configuration]]
== Áp dụng Global Configuration cho mọi HTTP Client

Bất kể underlying technology, mọi HTTP client có common setting:

* Connection timeout.
* Read timeout.
* Cách xử lý HTTP redirect.
* Cách xử lý HTTP cookie.
* SSL bundle dùng khi kết nối.

Các setting này được biểu diễn bằng javadoc:org.springframework.boot.http.client.HttpClientSettings[] và có thể truyền vào method `build(...)` của javadoc:org.springframework.boot.http.client.reactive.ClientHttpConnectorBuilder[] và javadoc:org.springframework.boot.http.client.ClientHttpRequestFactoryBuilder[].

Để áp dụng cùng configuration cho mọi auto-configured client, dùng property `spring.http.clients`:

[configprops,yaml]
----
spring:
  http:
    clients:
      connect-timeout: 2s
      read-timeout: 1s
      redirects: dont-follow
      cookie-handling: disable
----

Khi `spring.http.clients.cookie-handling` không được đặt, default cookie handling của underlying HTTP client library được dùng.
Default khác nhau: Apache HttpComponents và Jetty lưu cookie rồi gửi trong request sau, trong khi JDK client bỏ qua.
Khi cookie handling được enable, mỗi underlying HTTP client instance dùng cookie store riêng.
Reactor Netty và request factory `simple` không hỗ trợ cookie handling nên `enable` sẽ fail với các client này, còn `enable-when-possible` giữ nguyên.
