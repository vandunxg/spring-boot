[[actuator.cloud-foundry]]
= Hỗ trợ Cloud Foundry

Module `spring-boot-cloudfoundry` của Spring Boot (thuộc `spring-boot-starter-cloudfoundry`) cung cấp support bổ sung, được activate khi deploy lên một Cloud Foundry instance tương thích.
Path `/cloudfoundryapplication` cung cấp một secured route thay thế tới tất cả các bean javadoc:org.springframework.boot.actuate.endpoint.annotation.Endpoint[format=annotation].

Extended support này cho phép các Cloud Foundry management UI (chẳng hạn web application dùng để xem các application đã deploy) được bổ sung Spring Boot Actuator information.
Ví dụ, application status page có thể hiển thị đầy đủ health information thay vì chỉ hiển thị status điển hình là "`running`" hoặc "`stopped`".

NOTE: Path `/cloudfoundryapplication` không thể được regular user truy cập trực tiếp.
Để sử dụng endpoint, bạn phải truyền kèm request một UAA token hợp lệ.



[[actuator.cloud-foundry.disable]]
== Tắt hỗ trợ Actuator mở rộng cho Cloud Foundry

Nếu muốn disable hoàn toàn các endpoint `/cloudfoundryapplication`, bạn có thể thêm setting sau vào file `application.properties`:

[configprops,yaml]
----
management:
  cloudfoundry:
    enabled: false
----



[[actuator.cloud-foundry.ssl]]
== Self-signed Certificate trong Cloud Foundry

Mặc định, security verification cho các endpoint `/cloudfoundryapplication` thực hiện SSL call tới nhiều Cloud Foundry service.
Nếu các service UAA hoặc Cloud Controller của bạn sử dụng self-signed certificate, bạn cần set property sau:

[configprops,yaml]
----
management:
  cloudfoundry:
    skip-ssl-validation: true
----



[[actuator.cloud-foundry.custom-context-path]]
== Context Path tùy chỉnh

Nếu context-path của server được configure thành giá trị khác `/`, các Cloud Foundry endpoint sẽ không available tại root của application.
Ví dụ, nếu `server.servlet.context-path=/app`, các Cloud Foundry endpoint sẽ available tại `/app/cloudfoundryapplication/*`.

Nếu muốn các Cloud Foundry endpoint luôn available tại `/cloudfoundryapplication/*`, bất kể context-path của server, bạn cần explicitly configure điều này trong application.
