[[actuator.cloud-foundry]]
= Cloud Foundry Support

Module `spring-boot-cloudfoundry` của Spring Boot (thuộc `spring-boot-starter-cloudfoundry`) cung cấp support bổ sung được activate khi deploy lên compatible Cloud Foundry instance.
Path `/cloudfoundryapplication` cung cấp secured route thay thế tới mọi bean javadoc:org.springframework.boot.actuate.endpoint.annotation.Endpoint[format=annotation].

Extended support cho phép Cloud Foundry management UI được bổ sung Spring Boot actuator information.
Ví dụ application status page có thể hiển thị full health information thay vì chỉ "running" hoặc "stopped".

NOTE: Path `/cloudfoundryapplication` không accessible trực tiếp với regular user.
Để dùng endpoint phải truyền valid UAA token.

[[actuator.cloud-foundry.disable]]
== Disable Extended Cloud Foundry Actuator Support

Để disable hoàn toàn endpoint `/cloudfoundryapplication`:

[configprops,yaml]
----
management:
  cloudfoundry:
    enabled: false
----

[[actuator.cloud-foundry.ssl]]
== Cloud Foundry Self-signed Certificates

Mặc định security verification cho `/cloudfoundryapplication` endpoint thực hiện SSL call tới nhiều Cloud Foundry service.
Nếu UAA hoặc Cloud Controller dùng self-signed certificate:

[configprops,yaml]
----
management:
  cloudfoundry:
    skip-ssl-validation: true
----

== Custom Context Path
