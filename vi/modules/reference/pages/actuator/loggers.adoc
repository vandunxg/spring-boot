[[actuator.loggers]]
= Loggers

Spring Boot Actuator có khả năng xem và cấu hình log level của application tại runtime.
Có thể xem toàn bộ danh sách hoặc configuration của một logger riêng.
Configuration gồm explicit logging level và effective logging level do logging framework cung cấp.
Các level có thể là:

* `TRACE`
* `DEBUG`
* `INFO`
* `WARN`
* `ERROR`
* `FATAL`
* `OFF`
* `null`

`null` nghĩa là không có explicit configuration.

[[actuator.loggers.configure]]
== Configure Logger

Để cấu hình logger cụ thể, gửi `POST` với partial entity tới resource URI:

[source,json]
----
{
	"configuredLevel": "DEBUG"
}
----

TIP: Để "`reset`" specific level của logger và dùng default configuration, truyền `null` làm `configuredLevel`.

[[actuator.loggers.opentelemetry]]
== OpenTelemetry

Mặc định logging qua OpenTelemetry chưa được cấu hình.
Cần cung cấp location của OpenTelemetry logs endpoint:

[configprops,yaml]
----
management:
  opentelemetry:
    logging:
      export:
        otlp:
          endpoint: "https://otlp.example.com:4318/v1/logs"
----

Các property `management.opentelemetry.logging.export.*` dùng cấu hình javadoc:io.opentelemetry.sdk.logs.export.BatchLogRecordProcessor[].
Ví dụ đổi export interval thành 15 giây:

[configprops,yaml]
----
management:
  opentelemetry:
    logging:
      export:
        schedule-delay: "15s"
----

Các property `management.opentelemetry.logging.limits.*` dùng cấu hình log record limit.
Ví dụ giới hạn 64 attribute mỗi log record và max attribute value length 256 character:

[configprops,yaml]
----
management:
  opentelemetry:
    logging:
      limits:
        max-attributes: 64
        max-attribute-value-length: 256
----

Nếu cần kiểm soát hoàn toàn, register custom bean javadoc:io.opentelemetry.sdk.logs.LogLimits[].

NOTE: OpenTelemetry Logback appender và Log4j appender không thuộc Spring Boot.
Xem https://github.com/open-telemetry/opentelemetry-java-instrumentation/tree/main/instrumentation/logback/logback-appender-1.0/library[OpenTelemetry Logback appender] hoặc https://github.com/open-telemetry/opentelemetry-java-instrumentation/tree/main/instrumentation/log4j/log4j-appender-2.17/library[OpenTelemetry Log4j2 appender] trong https://github.com/open-telemetry/opentelemetry-java-instrumentation[OpenTelemetry Java instrumentation GitHub repository].

TIP: Cần cấu hình appender trong `logback-spring.xml` hoặc `log4j2-spring.xml` để OpenTelemetry logging hoạt động.

`OpenTelemetryAppender` cho cả Logback và Log4j cần access javadoc:io.opentelemetry.api.OpenTelemetry[] instance.
Instance phải được set programmatically khi application startup:

include-code::OpenTelemetryAppenderInitializer[]
