[[actuator.enabling]]
= Bật các production-ready feature

Module {code-spring-boot}/module/spring-boot-actuator[`spring-boot-actuator`] cung cấp toàn bộ production-ready feature của Spring Boot.
Cách được khuyến nghị để enable các feature là thêm dependency vào starter `spring-boot-starter-actuator`.

.Định nghĩa Actuator
****
Actuator là thuật ngữ trong manufacturing, dùng để chỉ một mechanical device có chức năng di chuyển hoặc điều khiển một thứ gì đó.
Actuator có thể tạo chuyển động lớn từ một thay đổi nhỏ.
****

Để thêm actuator vào một project dựa trên Maven, hãy thêm dependency starter sau:

[source,xml]
----
<dependencies>
	<dependency>
		<groupId>org.springframework.boot</groupId>
		<artifactId>spring-boot-starter-actuator</artifactId>
	</dependency>
</dependencies>
----

Với Gradle, sử dụng declaration sau:

[source,gradle]
----
dependencies {
	implementation 'org.springframework.boot:spring-boot-starter-actuator'
}
----
