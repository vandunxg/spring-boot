[[web]]
= Web

Spring Boot rất phù hợp để phát triển web application.
Bạn có thể tạo một self-contained HTTP server bằng embedded Tomcat, Jetty hoặc Netty.
Hầu hết web application sử dụng module `spring-boot-starter-webmvc` để nhanh chóng đưa ứng dụng vào hoạt động.
Bạn cũng có thể chọn xây dựng reactive web application bằng module `spring-boot-starter-webflux`.

Nếu chưa từng phát triển một Spring Boot web application, bạn có thể làm theo ví dụ "`Hello World!`" trong phần xref:tutorial:first-application/index.adoc[Bắt đầu].
