[[web]]
= Web

Spring Boot rất phù hợp để phát triển web application.
Bạn có thể tạo một HTTP server self-contained bằng embedded Tomcat, Jetty hoặc Netty.
Hầu hết web application sử dụng module `spring-boot-starter-webmvc` để có thể bắt đầu nhanh chóng.
Bạn cũng có thể chọn xây dựng reactive web application bằng module `spring-boot-starter-webflux`.

Nếu chưa từng phát triển Spring Boot web application, bạn có thể làm theo ví dụ "`Hello World!`" trong phần xref:tutorial:first-application/index.adoc[Getting started].
