[[testing.test-modules]]
= Test Module

Spring Boot cung cấp nhiều focused, feature-specific module `-test`:

[cols="1,3"]
|===
|Module | Mục đích

|`spring-boot-cache-test`
|Test application dùng cache abstraction của Spring Framework.

|`spring-boot-data-cassandra-test`
|Test application dùng Spring Data Cassandra. Cung cấp test slice `@DataCassandraTest`.

|`spring-boot-data-couchbase-test`
|Test application dùng Spring Data Couchbase. Cung cấp `@DataCouchbaseTest`.

|`spring-boot-data-elasticsearch-test`
|Test application dùng Spring Data Elasticsearch. Cung cấp `@DataElasticsearchTest`.

|`spring-boot-data-jdbc-test`
|Test application dùng Spring Data JDBC. Cung cấp `@DataJdbcTest`.

|`spring-boot-data-jpa-test`
|Test application dùng Spring Data JPA. Cung cấp `@DataJpaTest`.

|`spring-boot-data-ldap-test`
|Test application dùng Spring Data LDAP. Cung cấp `@DataLdapTest`.

|`spring-boot-mongodb-test`
|Test application dùng Spring Data MongoDB. Cung cấp `@DataMongoTest`.

|`spring-boot-data-neo4j-test`
|Test application dùng Spring Data JPA. Cung cấp `@DataNeo4jTest`.

|`spring-boot-data-r2dbc-test`
|Test application dùng Spring Data R2DBC. Cung cấp `@DataR2dbcTest`.

|`spring-boot-data-redis-test`
|Test application dùng Spring Data Redis. Cung cấp `@DataRedisTest`.

|`spring-boot-graphql-test`
|Test application dùng Spring GraphQL. Cung cấp `@GraphQlTest`.

|`spring-boot-grpc-test`
|Test application dùng Spring gRPC.

|`spring-boot-jdbc-test`
|Test application dùng Spring JDBC. Cung cấp `@JdbcTest`.

|`spring-boot-jooq-test`
|Test application dùng jOOQ. Cung cấp `@JooqTest`.

|`spring-boot-jpa-test`
|Test application dùng JPA.

|`spring-boot-micrometer-metrics-test`
|Test application dùng Micrometer Metrics.

|`spring-boot-micrometer-tracing-test`
|Test application dùng Micrometer Tracing.

|`spring-boot-restclient-test`
|Test application dùng REST client. Cung cấp `@RestClientTest`.

|`spring-boot-security-test`
|Test application dùng Spring Security.

|`spring-boot-webserver-test`
|Test application dùng implementation `WebServer`. Cung cấp annotation `@AutoconfigureWebServer`.

|`spring-boot-webclient-test`
|Test application dùng `WebClient`. Cung cấp `@WebClientTest`.

|`spring-boot-webflux-test`
|Test application dùng Spring WebFlux. Cung cấp `@WebFluxTest`.

|`spring-boot-webmvc-test`
|Test application dùng Spring Web MVC. Cung cấp `@WebMvcTest`.

|`spring-boot-webservices-test`
|Test application dùng Spring Web Services. Cung cấp test slice `@WebServiceClientTest` và `@WebServiceServerTest`.

|===
