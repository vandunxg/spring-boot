[[testing.test-modules]]
= Các Test Module

Spring Boot cung cấp một số module `-test` tập trung, dành riêng cho từng feature:

[cols="1,3"]
|===
|Module | Mục đích

|`spring-boot-cache-test`
|Test các application sử dụng cache abstraction của Spring Framework.

|`spring-boot-data-cassandra-test`
|Test các application sử dụng Spring Data Cassandra. Cung cấp test slice `@DataCassandraTest`.

|`spring-boot-data-couchbase-test`
|Test các application sử dụng Spring Data Couchbase. Cung cấp test slice `@DataCouchbaseTest`.

|`spring-boot-data-elasticsearch-test`
|Test các application sử dụng Spring Data Elasticsearch. Cung cấp test slice `@DataElasticsearchTest`.

|`spring-boot-data-jdbc-test`
|Test các application sử dụng Spring Data JDBC. Cung cấp test slice `@DataJdbcTest`.

|`spring-boot-data-jpa-test`
|Test các application sử dụng Spring Data JPA. Cung cấp test slice `@DataJpaTest`.

|`spring-boot-data-ldap-test`
|Test các application sử dụng Spring Data LDAP. Cung cấp test slice `@DataLdapTest`.

|`spring-boot-mongodb-test`
|Test các application sử dụng Spring Data MongoDB. Cung cấp test slice `@DataMongoTest`.

|`spring-boot-data-neo4j-test`
|Test các application sử dụng Spring Data JPA. Cung cấp test slice `@DataNeo4jTest`.

|`spring-boot-data-r2dbc-test`
|Test các application sử dụng Spring Data R2DBC. Cung cấp test slice `@DataR2dbcTest`.

|`spring-boot-data-redis-test`
|Test các application sử dụng Spring Data Redis. Cung cấp test slice `@DataRedisTest`.

|`spring-boot-graphql-test`
|Test các application sử dụng Spring GraphQL. Cung cấp test slice `@GraphQlTest`.

|`spring-boot-grpc-test`
|Test các application sử dụng Spring gRPC.

|`spring-boot-jdbc-test`
|Test các application sử dụng Spring JDBC. Cung cấp test slice `@JdbcTest`.

|`spring-boot-jooq-test`
|Test các application sử dụng jOOQ. Cung cấp test slice `@JooqTest`.

|`spring-boot-jpa-test`
|Test các application sử dụng JPA.

|`spring-boot-micrometer-metrics-test`
|Test các application sử dụng Micrometer Metrics.

|`spring-boot-micrometer-tracing-test`
|Test các application sử dụng Micrometer Tracing.

|`spring-boot-restclient-test`
|Test các application sử dụng REST client. Cung cấp test slice `@RestClientTest`.

|`spring-boot-security-test`
|Test các application sử dụng Spring Security.

|`spring-boot-webserver-test`
|Test các application sử dụng các implementation của `WebServer`. Cung cấp annotation `@AutoconfigureWebServer`.

|`spring-boot-webclient-test`
|Test các application sử dụng `WebClient`. Cung cấp test slice `@WebClientTest`.

|`spring-boot-webflux-test`
|Test các application sử dụng Spring WebFlux. Cung cấp test slice `@WebFluxTest`.

|`spring-boot-webmvc-test`
|Test các application sử dụng Spring Web MVC. Cung cấp test slice `@WebMvcTest`.

|`spring-boot-webservices-test`
|Test các application sử dụng Spring Web Services. Cung cấp test slice `@WebServiceClientTest` và `@WebServiceServerTest`.

|===
