[[testing.spring-applications]]
= Kiểm thử ứng dụng Spring

Một trong những ưu điểm lớn của dependency injection là giúp code của bạn dễ unit test hơn.
Bạn có thể instantiate object bằng operator `new` mà không cần đến Spring.
Bạn cũng có thể dùng _mock object_ thay cho dependency thật.

Thông thường, bạn cần chuyển từ unit test sang integration test (với một Spring javadoc:org.springframework.context.ApplicationContext[]).
Việc có thể thực hiện integration test mà không cần deploy application hoặc kết nối tới infrastructure khác rất hữu ích.

Spring Framework có một test module chuyên dụng cho kiểu integration test này.
Bạn có thể khai báo dependency trực tiếp tới `org.springframework:spring-test` hoặc dùng starter `spring-boot-starter-test` để dependency này được kéo vào transitively.

Nếu chưa từng sử dụng module `spring-test`, bạn nên bắt đầu bằng cách đọc {url-spring-framework-docs}/testing.html[phần liên quan] trong tài liệu tham khảo của Spring Framework.
