[[build-tool-plugins.other-build-systems]]
= Hỗ trợ build system khác

Nếu muốn dùng build tool khác Maven, Gradle hoặc Ant, nhiều khả năng bạn cần tự phát triển plugin riêng.
Executable jar phải theo một format cụ thể và một số entry phải được ghi ở dạng không nén (xem phần xref:specification:/executable-jar/index.adoc[executable jar format] trong appendix để biết chi tiết).

Maven plugin và Gradle plugin của Spring Boot đều dùng `spring-boot-loader-tools` để tạo jar.
Nếu cần, bạn có thể dùng trực tiếp library này.

[[build-tool-plugins.other-build-systems.repackaging-archives]]
== Repackage archive

Để repackage một archive có sẵn thành self-contained executable archive, dùng javadoc:org.springframework.boot.loader.tools.Repackager[].
Class javadoc:org.springframework.boot.loader.tools.Repackager[] nhận một constructor argument duy nhất trỏ tới jar hoặc war archive có sẵn.
Dùng một trong hai method `repackage()` khả dụng để thay thế file gốc hoặc ghi ra đích mới.
Cũng có thể cấu hình nhiều setting khác trên repackager trước khi chạy.

[[build-tool-plugins.other-build-systems.nested-libraries]]
== Nested Library

Khi repackage một archive, bạn có thể include reference tới các file dependency bằng interface javadoc:org.springframework.boot.loader.tools.Libraries[].
Chúng tôi không cung cấp implementation cụ thể nào của javadoc:org.springframework.boot.loader.tools.Libraries[] ở đây vì chúng thường phụ thuộc vào từng build system.

Nếu archive đã chứa sẵn library, bạn có thể dùng javadoc:org.springframework.boot.loader.tools.Libraries#NONE[].

[[build-tool-plugins.other-build-systems.finding-main-class]]
== Tìm Main Class

Nếu không dùng `Repackager.setMainClass()` để chỉ định main class, repackager dùng https://asm.ow2.io/[ASM] để đọc class file và cố tìm class phù hợp có method `public static void main(String[] args)`.
Một exception sẽ được ném ra nếu tìm thấy nhiều hơn một ứng viên.
