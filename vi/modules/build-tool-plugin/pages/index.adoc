[[build-tool-plugins]]
= Build Tool Plugins

Spring Boot cung cấp các build tool plugin cho Maven và Gradle.
Các plugin cung cấp nhiều tính năng, bao gồm việc đóng gói các executable jar.
Phần này cung cấp thêm chi tiết về cả hai plugin, cũng như hỗ trợ trong trường hợp bạn cần mở rộng một build system chưa được hỗ trợ.
Nếu bạn mới bắt đầu, trước tiên có thể đọc xref:reference:using/build-systems.adoc[] trong phần xref:reference:using/index.adoc[].
